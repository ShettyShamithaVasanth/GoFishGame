# Fix: Online Gameplay Visual Sequence for Book + Hand Refill

## Problem

In "Play with Friends" online mode, when a player's hand becomes empty after forming a book and cards are drawn from the deck (refill), the visual sequence is wrong:

**Current (broken):**
1. Deck visual disappears
2. Book formation animation plays
3. Hand cards fill up instantly (from state sync)
4. Card flying animation plays (too late)

**Expected (correct - same as offline):**
1. Book formation animation plays first
2. Deck visual updates (shows empty/fewer cards)
3. Card flying animation from deck to player
4. Hand cards fill up

## Root Cause

In `GameManager.cs` → `PlayTurnResultCoroutine`, the online result handler:

1. **Refill cards are NOT added to the local player model** during animation — they only appear later when `DelayedStateSync` (5s delay) runs and adds them via `ApplyPrivateHand`
2. **The drawn card in GO FISH Phase 2 is NOT added to the local model** — same issue
3. **Book cards are only removed from the LOCAL player's model** — other players' models still have them, causing stale visual state
4. **Missing `players[id].AddCard(card)` calls** after each `AnimateCardMove` in refill sections

Compare with offline flow (`HandleBook` + `RefillHandIfEmpty`) which correctly:
- Adds cards to model after each animation (`player.AddCard(drawn)`)
- Removes book cards from model
- Calls `RefreshAllHands` at the right times

## Fix — Only modify `GameManager.cs` method `PlayTurnResultCoroutine`

### Change 1: SUCCESS case — Remove book cards for ALL players

**File:** `Assets/Scripts/GameManager.cs`
**Location:** `PlayTurnResultCoroutine`, inside the `if (data.bookFormed)` block (around line 2282)

**Current code (line ~2282):**
```csharp
if (bookLocalId == myLocalId)
{
    List<Card> toRemove = players[bookLocalId].PlayerHand.GetCardsByRank(data.bookRank);
    foreach (Card c in toRemove)
    {
        players[bookLocalId].PlayerHand.RemoveCard(c);
    }
}
```

**Fixed code:**
```csharp
List<Card> toRemove = players[bookLocalId].PlayerHand.GetCardsByRank(data.bookRank);
foreach (Card c in toRemove)
{
    players[bookLocalId].PlayerHand.RemoveCard(c);
}
```

Remove the `if (bookLocalId == myLocalId)` guard — book cards should be removed from the model for ALL players, not just the local player. This ensures `RefreshAllHands` shows the correct state for everyone.

### Change 2: SUCCESS case — Add refill cards to model after animation

**Location:** `PlayTurnResultCoroutine`, inside the refill `foreach` loop (around line 2343)

**Current code:**
```csharp
foreach (int value in data.handRefillCards)
{
    RemoveTopDeckVisual();
    Card refillCard = ConvertToCard(value);
    yield return StartCoroutine(
        AnimateCardMove(deckPosition, refillUI.transform, refillCard, refillPlayerId)
    );
}
RefreshAllHands();
```

**Fixed code:**
```csharp
foreach (int value in data.handRefillCards)
{
    RemoveTopDeckVisual();
    Card refillCard = ConvertToCard(value);
    yield return StartCoroutine(
        AnimateCardMove(deckPosition, refillUI.transform, refillCard, refillPlayerId)
    );
    players[refillPlayerId].AddCard(refillCard);
}
RefreshAllHands();
```

Add `players[refillPlayerId].AddCard(refillCard)` after each animation so the model is updated before `RefreshAllHands`.

### Change 3: GO FISH Phase 2 — Add drawn card to model

**Location:** `PlayTurnResultCoroutine`, GO FISH Phase 2 section (around line 2505)

**Current code:**
```csharp
yield return StartCoroutine(
    AnimateCardMove(deckPosition, askerUI.transform, drawn, asker.PlayerID)

```

**Fixed code:**
```csharp
yield return StartCoroutine(
    AnimateCardMove(deckPosition, askerUI.transform, drawn, asker.PlayerID)
);
players[asker.PlayerID].AddCard(drawn);
RefreshAllHands();
```

### Change 4: GO FISH Phase 2 — Remove book cards for ALL players (same as Change 1)

**Location:** `PlayTurnResultCoroutine`, GO FISH Phase 2 book handling (around line 2538)

Same fix as Change 1 — remove the `if (bookLocalId == myLocalId)` guard.

### Change 5: GO FISH Phase 2 — Add refill cards to model (same as Change 2)

**Location:** `PlayTurnResultCoroutine`, GO FISH Phase 2 refill section (around line 2599)

Same fix as Change 2 — add `players[refillPlayerId].AddCard(refillCard)` after each animation.

## Why This Works

The offline flow already works correctly because:
1. `HandleBook` removes book cards from model → `RefreshAllHands` shows empty hand
2. `RefillHandIfEmpty` adds cards to model after each animation → `RefreshAllHands` shows full hand

The online fix mirrors this by:
1. Removing book cards from model for ALL players (not just local)
2. Adding refill/drawn cards to model after each animation
3. Keeping `RefreshAllHands` calls at the same positions

The `DelayedStateSync` (5s delay) acts as a safety net, but the visual sequence now works correctly without relying on it.

## Visual Sequence After Fix (Online)

1. Ask popup shows (2s)
2. Reply popup shows (1.5s)
3. Transferred cards animate (target → asker)
4. `RefreshAllHands` — hand shows new cards
5. Book animation plays
6. Book cards removed from model
7. Score updated
8. `RefreshAllHands` — hand shows empty (book cards gone)
9. For each refill card:
   - `RemoveTopDeckVisual` — deck shows one fewer card
   - `AnimateCardMove` — card flies from deck to player
   - `AddCard` — card added to model
10. `RefreshAllHands` — hand shows new refill cards
11. `UpdateDeckVisualCount` — deck synced to final count

This matches the offline flow exactly.
