# Fix: Auto-end turn when player has no valid moves

## Problem

After a successful card transfer, the player gets another turn (correct Go Fish rule). But if the player has exhausted all valid rank+target combinations for this turn (e.g., all their ranks were already asked to all available targets), the game gets **stuck** — the player can't make any valid move but the turn never ends.

### Example Scenario (2-player)
1. P1 asks P2 for A → SUCCESS → P1 gets A, P1 continues
2. P1 asks P2 for J → SUCCESS → P1 gets J, P1 continues
3. P1 now has {A,A,J,J} and P2 has {K,10,8}
4. P1 can't ask P2 for A again (already asked this turn)
5. P1 can't ask P2 for J again (already asked this turn)
6. **STUCK** — no valid moves, but turn doesn't end

## Root Cause

- **AI already handles this correctly** — `AISelectRandomTarget()` checks `foundValidMove` and calls `EndTurn()` if false (GameManager.cs:605-609)
- **Human (offline)** — After successful transfer, `TransferCardsWithAnimation()` never checks if the human has valid moves (GameManager.cs:1189-1193)
- **Human (online)** — `PlayTurnResultCoroutine()` success path never checks valid moves (GameManager.cs:2254-2269)
- **Online also has**: Missing `completedRanks` tracking and missing local hand updates for transferred/drawn cards

## Changes

### 1. `Assets/Scripts/core/GameRules.cs` — Add `HasValidMove()` method

Add a static method that determines whether a player can make any valid ask this turn:

```csharp
public static bool HasValidMove(
    Player player,
    int[] activePlayers,
    int currentPlayerId,
    HashSet<string> askedRankTargetThisTurn,
    HashSet<int> completedRanks)
{
    List<Card> hand = player.PlayerHand.Cards;
    if (hand.Count == 0) return false;

    // Get unique non-completed ranks in player's hand
    HashSet<int> availableRanks = new HashSet<int>();
    foreach (Card c in hand)
    {
        if (!completedRanks.Contains(c.Rank))
            availableRanks.Add(c.Rank);
    }

    // Check if any rank can be asked to any target
    foreach (int rank in availableRanks)
    {
        foreach (int targetId in activePlayers)
        {
            if (targetId == currentPlayerId) continue;
            string key = targetId + "_" + rank;
            if (!askedRankTargetThisTurn.Contains(key))
                return true; // At least one valid move exists
        }
    }

    return false; // No valid moves
}
```

### 3. `Assets/Scripts/NetworkGameManager.cs` — Add `ForceNextTurnRpc`

Add a new RPC that allows clients to signal "I have no valid moves, advance the turn":

```csharp
[Rpc(SendTo.Server, InvokePermission = RpcInvokePermission.Everyone)]
public void ForceNextTurnRpc(RpcParams rpcParams = default)
{
    ulong senderId = rpcParams.Receive.SenderClientId;
    if (senderId != currentTurnPlayerId.Value) return;

    Debug.Log($"[SERVER-FORCE-NEXT] Client:{senderId} has no valid moves");
    NextTurn();
    BroadcastStateToAll();
}
```

## Edge Cases Handled

1. **Empty hand after book** → `HasValidMove` returns false → auto-end turn
2. **3+ player mode** → Check considers all targets, not just one
3. **Lucky draw with exhausted combos** → Checked after draw
4. **Book formed during transfer** → Check happens AFTER book resolution (including refill)
5. **Online state sync race** → Local hand is updated immediately; state sync overwrites later
