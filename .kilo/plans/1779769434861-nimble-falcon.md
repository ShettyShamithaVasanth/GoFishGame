# Plan: Online Hand Refill After Book Formation + Book Animation Delay

## Problem

When a player forms a book in **online mode**, all 4 cards are removed from their hand. If this leaves their hand empty, **no cards are dealt from the deck** to refill it. In offline mode, the `RefillHandIfEmpty` method handles this correctly: if a player has 0 cards after a book, up to 5 cards are drawn from the deck (or fewer if the deck has less than 5).

The book formation delay fix (1.5s gap before animation) was already applied in the current code.

## Offline Flow (Correct Reference)

`HandleBook()` (GameManager.cs:1417):
1. Animate book cards collecting
2. Remove cards from hand
3. Add point, update score
4. `RefreshAllHands()`
5. **`RefillHandIfEmpty(playerID)`** ← draws up to 5 cards with animation
6. Check deck empty → end game if needed

`RefillHandIfEmpty()` (GameManager.cs:925):
```
if hand.Count > 0 → yield break (skip)
drawCount = Min(5, deck.CardCount())
for each card: animate + add to hand
RefreshAllHands()
```

But currently `RefillHandIfEmpty` has `if (GameModeManager.isOnlineMode) { yield break; }` — it skips entirely in online mode.

## Online Flow (Current — Missing Refill)

**Server-side** (`NetworkGameManager.CheckForBook`, line 643):
- Detects 4-of-a-kind → removes cards from `player.hand` → increments `player.score`
- Does NOT check if hand is now empty
- Does NOT draw refill cards

**Client-side** (`GameManager.PlayTurnResultCoroutine`):
- After book animation, removes cards from local `Player` hand
- Does NOT check if hand is empty
- Does NOT trigger any refill

## Architecture Decision

This follows **server-authoritative** model (no client/host mixing):
- **Server** owns all game state: deck, hands, scores
- **Server** detects empty hand → draws refill cards → includes refill data in `TurnResultData`
- **Client** receives refill data → plays animations → updates local view

### File 2: `Assets/Scripts/NetworkGameManager.cs` — Server-side refill logic

#### Change 2a: New method `CheckAndRefillHand` on server

After `CheckForBook` removes cards and hand becomes empty, draw up to 5 cards:

```csharp
int[] CheckAndRefillHand(NetworkPlayer player)
{
    if (player.hand.Count > 0) return null;
    if (NetworkDeckManager.Instance.deck.Count == 0) return null;

    int drawCount = Mathf.Min(5, NetworkDeckManager.Instance.deck.Count);
    List<int> drawnCards = new List<int>();

    for (int i = 0; i < drawCount; i++)
    {
        int card = NetworkDeckManager.Instance.DrawCard();
        if (card == -1) break;
        player.AddCard(card);
        drawnCards.Add(card);
    }

    deckRemainingCards.Value = NetworkDeckManager.Instance.deck.Count;
    return drawnCards.ToArray();
}
```

### File 3: `Assets/Scripts/GameManager.cs` — Client-side refill animation

#### Change 3a: New method `AnimateOnlineRefill` in GameManager

This method plays card-draw animations for refill cards (matching offline `RefillHandIfEmpty` visual style):

```csharp
IEnumerator AnimateOnlineRefill(int playerID, int[] refillCardValues)
{
    int uiIndex = GetUIIndex(playerID);
    UIPlayer ui = uiPlayers[uiIndex];

    if (toastUI != null)
    {
        toastUI.ShowToastWithAutoHide(
            players[playerID].PlayerName + " drawing new cards...",
            3f
        );
    }

    foreach (int cardValue in refillCardValues)
    {
        Card card = ConvertToCard(cardValue);
        yield return StartCoroutine(
            AnimateCardMove(deckPosition, ui.transform, card, playerID)
        );
        RemoveTopDeckVisual();
    }

    RefreshAllHands();
}
```

## Flow Summary

### Online SUCCESS with Book + Refill:
1. Server: target gives cards to asker
2. Server: detects book → removes 4 cards → increments score
3. Server: detects empty hand → draws up to 5 cards from deck
4. Server: sends `TurnResultData` with `bookFormed=true` + `handRefilled=true` + `refillCards=[...]`
5. Client: animate transferred cards
6. Client: `RefreshAllHands()`
7. Client: wait 1.5s → book animation → wait 2s
8. Client: refill animation (cards fly from deck to player)
9. Client: `RefreshAllHands()`

### Online DRAW with Book + Refill:
1. Server: draws card → detects book → removes 4 cards → increments score
2. Server: detects empty hand → draws up to 5 cards from deck
3. Server: sends result with `bookFormed=true` + `handRefilled=true`
4. Client: animate drawn card
5. Client: `RefreshAllHands()`
6. Client: wait 1.5s → book animation → wait 2s
7. Client: refill animation
8. Client: `RefreshAllHands()`

## What This Does NOT Change

- **Offline gameplay**: `RefillHandIfEmpty` remains unchanged; offline `HandleBook` flow is untouched
- **Lobby system**: No changes to `LobbyManager`, `NetworkController`, `NetworkPlayer`, `NetworkPlayerManager`
- **MVC structure**: Server handles state logic, GameManager handles view/animation — proper separation
- **No client/host mixing**: All game state decisions happen on server; clients only receive data and play animations
