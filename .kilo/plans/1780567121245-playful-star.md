# Plan: Fix 4 compiler warnings in `QuickMatchService.cs`

## Warnings to resolve

| # | Code | Location | Cause |
|---|------|----------|-------|
| 1 | CS1998 | `StartHostFlow()` line 86 | `async Task` method contains no `await` |
| 2 | CS1998 | `StartClientFlow()` line 110 | `async Task` method contains no `await` |
| 3 | CS0414 | `pollInterval` line 44 | Field assigned but never read |
| 4 | CS0414 | `pollTimer` line 57 | Field assigned but never read |

All four originate from **stub/placeholder** code — the Relay + Lobby polling flow has not been implemented yet. The fix must therefore preserve the intended future shape of the API (async Task, configurable polling interval) without producing warnings today.

---

## Chosen approach (recommended)

Keep the methods async and the fields in place (they are part of the documented future contract), but silence the two specific warnings at the source using targeted `#pragma` directives. This is the standard Unity/.NET pattern for *intentional stubs* — it keeps the public API stable so callers like `CheckMatchReady()` (`await StartOnlineGame()`) continue to compile, and as soon as the Relay logic is wired in, removing the pragmas is a one-line cleanup.

### Why not the alternatives?
- **Removing `async` and returning `Task.CompletedTask`** — works, but every future addition of an `await` requires re-adding `async`; churn for no gain.
- **Adding a fake `await Task.Yield()`** — silences the warning but introduces a meaningless context switch at runtime (real cost in hot paths).
- **Deleting the unused fields** — they are `[SerializeField]` config (visible in the Inspector) and the matching `pollTimer` is already reset in `LeaveLobbyAndCleanup()`; deleting them removes configuration the designer will need when polling is implemented.

## Concrete edits to `Assets/Scripts/QuickMatchService.cs`

### Edit 1 — Silence CS0414 around the config/runtime block (lines 41–59)

Wrap the two unused fields with a disable/restore pragma pair so only those two fields are affected:

```csharp
[Header("Config")]
[SerializeField] private int requiredPlayers = 4;
[SerializeField] private float searchTimeout = 20f;
#pragma warning disable CS0414 // Field is assigned but its value is never used (polling not yet implemented)
[SerializeField] private float pollInterval = 2.5f;
#pragma warning restore CS0414
[SerializeField] private AvatarDatabase avatarDatabase;

[Header("Events")]
public System.Action<string, int, int> OnPlayerJoined;
public System.Action<int> OnPlayerLeft;
public System.Action OnMatchFound;
public System.Action OnTimeout;
public System.Action<string> OnError;

[Header("Runtime")]
private Lobby currentLobby;
private bool isSearching;
private float searchTimer;
#pragma warning disable CS0414 // Field is assigned but its value is never used (polling not yet implemented)
private float pollTimer;
#pragma warning restore CS0414
private bool isHost;
private string relayCode;
```
