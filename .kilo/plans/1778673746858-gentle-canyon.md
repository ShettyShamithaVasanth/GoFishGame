# ROOT CAUSE FOUND: Deck Invisible on Host

## Bug: `UpdateDeckVisualCount()` never activates card GameObjects

### Evidence
`CreateDeckVisual()` (line 328-331, used in offline mode) has:
```csharp
DOVirtual.DelayedCall(0.5f, () =>
{
    if (cardObj != null) cardObj.SetActive(true);  // ← activates the card!
}).SetLink(cardObj);
```

`UpdateDeckVisualCount()` (line 379, used in online mode) does NOT activate cards. Since `cardBackPrefab` starts **inactive**, `Instantiate` creates inactive copies that stay invisible.

## Fix Required: ONE line change in `Assets/Scripts/GameManager.cs`

### Line 379 — Add `cardObj.SetActive(true)` after Instantiate

**OLD (line 379):**
```csharp
            GameObject cardObj = Instantiate(cardBackPrefab, deckPosition);
            cardObj.transform.localPosition = new Vector3(0, i * 0.08f, 0);
```

**NEW:**
```csharp
            GameObject cardObj = Instantiate(cardBackPrefab, deckPosition);
            cardObj.SetActive(true);
            cardObj.transform.localPosition = new Vector3(0, i * 0.08f, 0);
```

That's it. One line fixes the deck visibility on both host and client.
