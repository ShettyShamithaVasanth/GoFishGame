# Fix Online Multiplayer — 5 Changes

## Problem 1: Server auto-draws on Go Fish (no deck click)
**Line:** `NetworkGameManager.cs:327` — `int drawnCard = NetworkDeckManager.Instance.DrawCard()` runs inside `RequestCardRpc`. Server draws immediately instead of waiting for player to click deck.

**Line:** `GameManager.cs:937` — `OnDeckClicked` returns `"ONLINE MODE → deck click ignored"` — deck click does nothing.

**Line:** `GameManager.cs:1495` — `OnGoFishButtonClicked` returns `"ONLINE MODE → GoFish handled by server"` — same problem.

**Fix:** Split into TWO server RPCs: `RequestCardRpc` (ask-only, no draw on Go Fish) + new `DrawCardRpc` (called when player clicks deck).

## Problem 2: Client side shows nothing
State sync timing issues. Previous 4 changes (WaitForDeckThenCreate coroutine, longer wait times) are already applied but don't help because the Go Fish flow is broken — the game auto-resolves before the client can interact.

## CHANGE 2: `NetworkGameManager.cs` — Add new DrawCardRpc method

**Find** (right after `RequestCardRpc` ends, before `[ClientRpc] void TurnResultClientRpc`):
```csharp

    void TurnResultClientRpc(TurnResultData data, ClientRpcParams rpcParams = default)
```

**Insert ABOVE it:**
```csharp
    [Rpc(SendTo.Server, InvokePermission = RpcInvokePermission.Everyone)]
    public void DrawCardRpc(int askedRank, RpcParams rpcParams = default)
    {
        ulong senderId = rpcParams.Receive.SenderClientId;
        if (senderId != currentTurnPlayerId.Value) return;

        var players = NetworkPlayerManager.Instance.players;
        NetworkPlayer sender = players.Find(p => p.OwnerClientId == senderId);
        if (sender == null) return;

        TurnResultData result = new TurnResultData
        {
            askerClientId = senderId,
            targetClientId = 0,
            rank = askedRank,
            success = false,
            transferCount = 0,
            goFish = false,
            drawnCardValue = -1,
            isLucky = false,
            bookFormed = false,
            bookRank = -1,
            continueTurn = false,
            nextTurnClientId = 0,
            deckRemaining = 0
        };

        int drawnCard = NetworkDeckManager.Instance.DrawCard();
        deckRemainingCards.Value = NetworkDeckManager.Instance.deck.Count;

        if (drawnCard != -1)
        {
            sender.AddCard(drawnCard);
            result.drawnCardValue = drawnCard;
            result.isLucky = (drawnCard / 10 == askedRank);

            int bookedRank = CheckForBook(sender);
            result.bookFormed = bookedRank != -1;
            if (result.bookFormed)
            {
                result.bookRank = bookedRank;
                result.bookPlayerClientId = sender.OwnerClientId;
                result.bookPlayerScore = sender.score.Value;
            }

            if (result.isLucky)
            {
                result.continueTurn = true;
            }
            else
            {
                result.continueTurn = false;
                NextTurn();
                result.nextTurnClientId = currentTurnPlayerId.Value;
            }
        }
        else
        {
            result.drawnCardValue = -1;
            result.isLucky = false;
            result.continueTurn = false;
            NextTurn();
            result.nextTurnClientId = currentTurnPlayerId.Value;
        }

        result.deckRemaining = NetworkDeckManager.Instance.deck.Count;

        TurnResultClientRpc(result);
        StartCoroutine(DelayedStateSync(7f));
    }

```

## Flow After Fix

1. Player selects rank → selects target → `HumanSelectTarget` sends `RequestCardRpc`
2. Server checks if target has rank
3. **If YES:** Server transfers cards, sends result, client shows ask→reply→transfer animation
4. **If NO:** Server sends Go Fish result (NO draw), client shows ask→reply→"Go Fish!" toast
5. Client sets `waitingForDeckClick = true`, shows "Click the deck"
6. Player clicks deck → `OnDeckClicked` calls `DrawCardRpc`
7. Server draws card, checks book/lucky, sends result
8. Client shows draw animation, handles turn continue/end
