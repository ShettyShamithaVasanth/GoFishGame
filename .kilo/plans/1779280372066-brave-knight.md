# Plan: Fix Client-Side Popup Display — Mirror Host-Side Ask/Target/Reply Popups on All Clients

## Problem
When the **host** (Maya) asks a client for cards, the host sees:
- `ShowAskPopup` — "Alex, do you have any 5s?"
- `ShowTargetPopup` — target player highlights
- `ShowReplyPopup` — "Yes, I have 2 5s." or "Go Fish!"

But the **client** (watching its own turn being asked about, or watching other players' turns) sees **NONE** of these popups. The `TurnResultClientRpc` fires on all clients, and `PlayTurnResultCoroutine` does show ask/reply popups — BUT only on the **asking player's** screen correctly. The **non-asking client** (the target being asked, or a 3rd observer) gets a broken experience.

## Root Cause Analysis

### Flow: Host asks Client for cards
1. Host clicks target → `HumanSelectTarget()` → `RequestCardRpc` sent to server
2. Server processes → sends `TurnResultClientRpc` to ALL clients
3. ALL clients call `PlayTurnResultCoroutine(data)`

### What happens on each client in `PlayTurnResultCoroutine`:

**SUCCESS case (line 2032-2117):**
- ✅ Shows `ShowAskPopup` on asker UI position — works on host (asker)
- ✅ Shows `ShowReplyPopup` on target UI position — works visually on client (they ARE the target)
- ✅ Animates card transfers
- ❌ BUT the **target popup** (`ShowTargetPopup`) is never called for the client — the client doesn't see itself being targeted with the highlight
- ❌ No toast message telling the client "X is asking you for Y"

**GO FISH Phase 1 (line 2120-2167):**
- ✅ Shows ask/reply popups
- ❌ `waitingForDeckClick = true` is set on ALL clients — but only the **asker** should draw from deck. The non-asking client gets stuck waiting for a deck click that never comes
- ❌ The target client sees "Go Fish!" reply but doesn't understand the context

**GO FISH Phase 2 (line 2170-2267):**
- ❌ Only the asker should see `waitingForDeckClick` being consumed — but Phase 1 already set it on all clients

## Fix Strategy

The key insight: `PlayTurnResultCoroutine` runs identically on ALL clients. We need to add **client-role awareness** — is this client the asker, the target, or an observer?

### Changes needed: 2 files

---

### File 1: `GameManager.cs` — Fix `PlayTurnResultCoroutine` (lines 2013-2267)

**Add role detection at the top of the coroutine:**
```csharp
ulong myClientId = NetworkManager.Singleton.LocalClientId;
bool iAmAsker = (data.askerClientId == myClientId);
bool iAmTarget = (data.targetClientId == myClientId);
```

**SUCCESS case fix (line 2032-2117):**
- If `iAmTarget` → show toast: `"{askerName} is asking you for {rank}s!"`
- Always show `ShowAskPopup` on asker UI and `ShowReplyPopup` on target UI (already works)
- Always show `ShowTargetPopup` on the target UI player (currently missing)

**GO FISH Phase 1 fix (line 2120-2167):**
- Only set `waitingForDeckClick = true` if `iAmAsker` — other clients should NOT wait for deck click
- If `iAmTarget` → show toast: `"{askerName} asked you for {rank}s — Go Fish!"`
- If NOT asker and NOT target (observer) → just show the popups as visual feedback, no interactivity

**GO FISH Phase 2 fix (line 2170-2267):**
- Only consume `waitingForDeckClick` if `iAmAsker`
- Show draw animation on all clients (already works)
- If `iAmTarget` → show toast about what happened

**Turn continuation (line 2239-2257):**
- Only show "Your turn!" toast if `players[askerId].IsHuman` AND `iAmAsker`

---

### File 2: `GameManager.cs` — Fix `HumanSelectTarget` (line 796-811)

The online mode path (line 796-811) only shows popups on the **asker's** screen:
```csharp
uiPlayers[currentUIIndex].ShowAskPopup(displayName, selectedRank);
currentTargetUI.ShowTargetPopup();
```
This is correct — the asker initiates locally, then `TurnResultClientRpc` propagates to all clients. No change needed here.

---

### File 3: `UIPlayer.cs` — Add `ShowBeingAskedPopup` (optional enhancement)

Add a method to show a different popup when this player is being asked:
```csharp
public void ShowBeingAskedPopup(string askerName, int rank)
{
    if (popup2 != null)
        popup2.SetActive(true);
    if (popup2Text != null)
        popup2Text.text = $"{askerName} asks: Do you have any {rank}s?";
}
```
This gives the target player clear feedback about what's happening.
