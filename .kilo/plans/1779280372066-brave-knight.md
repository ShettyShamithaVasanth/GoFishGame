# Plan: Add `FindUIPlayerByNetworkId` Method

## Current Lookup Chain (3 hops, fragile)
```
ulong networkId → GetLocalPlayerId(networkId) → int localSeatIndex
  → GetUIIndex(localSeatIndex) → int uiIndex
    → uiPlayers[uiIndex] → UIPlayer
```

This is used everywhere in `PlayTurnResultCoroutine`:
```csharp
int askerId = GetLocalPlayerId(data.askerClientId);    // hop 1
int askerUI = GetUIIndex(askerId);                       // hop 2
uiPlayers[askerUI].ShowAskPopup(...)                     // hop 3
```

## New Method (1 hop, clean)

### Add to `GameManager.cs` after `FindPlayerByNetworkId` (around line 1740)

```csharp
public UIPlayer FindUIPlayerByNetworkId(ulong networkId)
{
    Player player = FindPlayerByNetworkId(networkId);
    if (player == null) return null;
    int uiIndex = GetUIIndex(player.PlayerID);
    if (uiIndex >= 0 && uiIndex < uiPlayers.Length)
        return uiPlayers[uiIndex];
    return null;
}
```

This encapsulates the 3-hop chain into one reusable method. Any caller just does:
```csharp
UIPlayer askerUI = FindUIPlayerByNetworkId(data.askerClientId);
```
