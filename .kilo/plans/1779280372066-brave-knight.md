### File 1: `GameManager.cs` — Add debug logs to online gameplay events

Add a helper method at class level (after line ~65):
```csharp
string PlayerDebugInfo(int localPlayerId)
{
    if (players == null || localPlayerId < 0 || localPlayerId >= players.Length)
        return "[unknown]";
    Player p = players[localPlayerId];
    string seat = p.SeatId.HasValue ? p.SeatId.Value.ToString() : "n/a";
    string net = p.NetworkId ?? "n/a";
    return $"{p.PlayerName} [seat:{seat} net:{net}]";
}
```

## Debug Log Format
All logs use structured prefixes for easy filtering:
- `[NET-ASK]` — Player asking for cards
- `[NET-TRANSFER]` — Cards being transferred
- `[NET-GOFISH-P1]` — Go Fish phase 1 (ask failed)
- `[NET-GOFISH-P2]` — Go Fish phase 2 (card drawn)
- `[NET-DECK-CLICK]` — Player clicked deck
- `[NET-GOFISH-BTN]` — Player pressed Go Fish button
- `[NET-TURN-CHANGE]` — Turn changed
- `[NET-HAND-SYNC]` — Hand synced
- `[NET-STATE-SYNC]` — State synced
- `[NET-BOOK]` — Book completed
- `[NET-INIT]` — Player initialized
- `[SERVER-*]` — Server-side equivalents
