# Plan: Fix Popup Persistence in Online Mode (Complete)

## Root Cause

**Race condition** between `ApplyNetworkTurn` and `PlayTurnResultCoroutine`:

1. Server calls `NextTurn()` (changes `currentTurnPlayerId.Value`) **before** `TurnResultClientRpc`
2. On client: `currentTurnPlayerId` sync arrives first → `OnTurnchanged` → `ApplyNetworkTurn` → hides ALL popups, ends turns, starts new turn
3. On client: `TurnResultClientRpc` arrives shortly after → `PlayTurnResultCoroutine` starts
4. **Line 2026 unconditionally calls `ShowAskPopup`** → popup1 RE-APPEARS on the previous player's position
5. Phase 2 code never hides popup1
6. Phase 2 line 2246-2260 calls `StartTurn()` directly without `EndTurn()` on previous player — double-turn conflict with `ApplyNetworkTurn`

**Secondary issue:** Phase 2 (Go Fish draw result) re-shows the ask popup even though the ask happened in Phase 1. The ask popup is only relevant for SUCCESS and Phase 1.
