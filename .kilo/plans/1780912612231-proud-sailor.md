# Matchmaking Panel — Show All Players & Auto-Start (Full Implementation Plan)

## Problem
The matchmaking panel (`Play Online`) only shows the local player's name/avatar. Other players are never displayed. `QuickMatchService` has no actual Unity Lobby integration — all lobby/relay methods are stubs. There is no path to actually start an online game from matchmaking.

## Solution — 3 Files Changed

| File | Action | Purpose |
|------|--------|---------|
| `QuickMatchService.cs` | **Full rewrite** | Unity Lobby create/join, polling, relay setup, player tracking, events |
| `MatchmakingUIController.cs` | **Update** | Subscribe to events, render all player slots with name+avatar |
| `MatchmakingStarter.cs` | **Simplify** | Entry point only — set local slot, call FindMatch |

All other files are **untouched** — offline mode, Play-with-Friends lobby, and gameplay remain unaffected.

### Remove ALL existing code and replace with:

```csharp
using UnityEngine;
using Unity.Services.Lobbies;
using Unity.Services.Lobbies.Models;
using Unity.Services.Relay;
using Unity.Services.Relay.Models;
using Unity.Services.Authentication;
using Unity.Netcode;
using Unity.Netcode.Transports.UTP;
using System.Collections;
using System.Collections.Generic;
using System.Threading.Tasks;

public class QuickMatchService : MonoBehaviour
{
    public static QuickMatchService Instance;

    [Header("Config")]
    [SerializeField] private int requiredPlayers = 4;
    [SerializeField] private float searchTimeout = 20f;
    [SerializeField] private float pollInterval = 2.5f;
    [SerializeField] private AvatarDatabase avatarDatabase;

    [Header("Events")]
    public System.Action<string, int, int> OnPlayerJoined;
    public System.Action<int> OnPlayerLeft;
    public System.Action OnMatchFound;
    public System.Action OnTimeout;
    public System.Action<string> OnError;

    [Header("Runtime")]
    private Lobby currentLobby;
    private bool isSearching;
    private float searchTimer;
    private float pollTimer;
    private bool isHost;
    private HashSet<string> previousPlayerIds = new HashSet<string>();

    public bool IsSearching => isSearching;
    public float RemainingSeconds => Mathf.Max(0f, searchTimeout - searchTimer);
    public AvatarDatabase AvatarDB => avatarDatabase;

    private void Awake()
    {
        Instance = this;
    }

    private void Update()
    {
        if (!isSearching) return;

        searchTimer += Time.deltaTime;
        if (searchTimer >= searchTimeout)
        {
            HandleTimeout();
            return;
        }

        pollTimer += Time.deltaTime;
        if (pollTimer >= pollInterval)
        {
            pollTimer = 0f;
            _ = PollLobby();
        }
    }

    // ─────────── PUBLIC API ───────────

    public async void FindMatch()
    {
        Debug.Log("[QM] FindMatch called");
        searchTimer = 0f;
        pollTimer = 0f;
        previousPlayerIds.Clear();

        bool joined = await TryJoinExistingLobby();
        if (!joined)
        {
            await CreateNewLobby();
        }

        isSearching = true;
        NotifyAllPlayers();
    }

    public void Cancel()
    {
        isSearching = false;
        StartCoroutine(LeaveAndCleanup());
    }

    // ─────────── LOBBY CREATE / JOIN ───────────

    async Task<bool> TryJoinExistingLobby()
    {
        try
        {
            var options = new QueryLobbiesOptions
            {
                Filters = new List<QueryFilter>
                {
                    new QueryFilter(
                        QueryFilter.FieldOptions.AvailableSlots,
                        "1",
                        QueryFilter.OpOptions.GT),
                    new QueryFilter(
                        QueryFilter.FieldOptions.Name,
                        "QuickMatch",
                        QueryFilter.OpOptions.EQ)
                }
            };

            QueryResponse response = await LobbyService.Instance.QueryLobbiesAsync(options);

            if (response.Results == null || response.Results.Count == 0)
                return false;

            Lobby target = response.Results[0];
            currentLobby = await LobbyService.Instance.JoinLobbyByIdAsync(target.Id);
            isHost = false;

            await SetMyPlayerData();
            currentLobby = await LobbyService.Instance.GetLobbyAsync(currentLobby.Id);

            Debug.Log("[QM] Joined existing lobby: " + currentLobby.Id);
            return true;
        }
        catch (System.Exception e)
        {
            Debug.LogWarning("[QM] Join failed: " + e.Message);
            return false;
        }
    }

    async Task CreateNewLobby()
    {
        try
        {
            var createOptions = new CreateLobbyOptions
            {
                IsPrivate = false,
                Data = new Dictionary<string, DataObject>
                {
                    {
                        "mode",
                        new DataObject(DataObject.VisibilityOptions.Public, "QuickMatch")
                    }
                }
            };

            currentLobby = await LobbyService.Instance.CreateLobbyAsync(
                "QuickMatch", requiredPlayers, createOptions);

            isHost = true;

            await SetMyPlayerData();
            currentLobby = await LobbyService.Instance.GetLobbyAsync(currentLobby.Id);

            Debug.Log("[QM] Created lobby: " + currentLobby.Id);
        }
        catch (System.Exception e)
        {
            Debug.LogError("[QM] Create lobby failed: " + e.Message);
            OnError?.Invoke("Failed to create match");
        }
    }

    async Task SetMyPlayerData()
    {
        if (currentLobby == null) return;

        string playerId = AuthenticationService.Instance.PlayerId;

        await LobbyService.Instance.UpdatePlayerAsync(
            currentLobby.Id,
            playerId,
            new UpdatePlayerOptions
            {
                Data = new Dictionary<string, PlayerDataObject>
                {
                    {
                        "name",
                        new PlayerDataObject(
                            PlayerDataObject.VisibilityOptions.Member,
                            string.IsNullOrEmpty(ProfileData.PlayerName)
                                ? "Player" : ProfileData.PlayerName)
                    },
                    {
                        "avatar",
                        new PlayerDataObject(
                            PlayerDataObject.VisibilityOptions.Member,
                            ProfileData.PlayerAvatarIndex.ToString())
                    }
                }
            });
    }

    // ─────────── POLLING ───────────

    async Task PollLobby()
    {
        if (currentLobby == null) return;

        try
        {
            currentLobby = await LobbyService.Instance.GetLobbyAsync(currentLobby.Id);
            DetectPlayerChanges();

            if (currentLobby.Players.Count >= requiredPlayers)
            {
                HandleMatchFound();
            }
        }
        catch (LobbyServiceException e)
        {
            Debug.LogWarning("[QM] Poll failed: " + e.Message);
            if (e.Reason == LobbyExceptionReason.LobbyNotFound)
            {
                currentLobby = null;
                HandleTimeout();
            }
        }
    }

    void DetectPlayerChanges()
    {
        if (currentLobby == null) return;

        HashSet<string> currentIds = new HashSet<string>();
        for (int i = 0; i < currentLobby.Players.Count; i++)
        {
            currentIds.Add(currentLobby.Players[i].Id);
        }

        // New players
        foreach (var player in currentLobby.Players)
        {
            if (!previousPlayerIds.Contains(player.Id))
            {
                string name = GetPlayerName(player);
                int avatarIdx = GetPlayerAvatarIndex(player);
                int slot = currentLobby.Players.IndexOf(player);
                OnPlayerJoined?.Invoke(name, avatarIdx, slot);
            }
        }

        // Left players
        foreach (string oldId in previousPlayerIds)
        {
            if (!currentIds.Contains(oldId))
            {
                OnPlayerLeft?.Invoke(-1);
            }
        }

        previousPlayerIds = currentIds;
    }

    void NotifyAllPlayers()
    {
        if (currentLobby == null) return;
        previousPlayerIds.Clear();
        DetectPlayerChanges();
    }

    // ─────────── MATCH FOUND ───────────

    async void HandleMatchFound()
    {
        if (!isSearching) return;
        isSearching = false;

        Debug.Log("[QM] Match found! All " + requiredPlayers + " players joined.");
        OnMatchFound?.Invoke();

        if (isHost)
        {
            await HostStartGame();
        }
        else
        {
            await ClientJoinGame();
        }
    }

    async Task HostStartGame()
    {
        try
        {
            // 1. Create Relay
            Allocation allocation = await RelayService.Instance.CreateAllocationAsync(requiredPlayers);
            string joinCode = await RelayService.Instance.GetJoinCodeAsync(allocation.AllocationId);

            // 2. Store relay code in lobby
            await LobbyService.Instance.UpdateLobbyAsync(
                currentLobby.Id,
                new UpdateLobbyOptions
                {
                    Data = new Dictionary<string, DataObject>
                    {
                        {
                            "relayCode",
                            new DataObject(DataObject.VisibilityOptions.Member, joinCode)
                        }
                    }
                });

            // 3. Configure transport
            var transport = NetworkManager.Singleton.GetComponent<UnityTransport>();
            transport.SetRelayServerData(
                allocation.RelayServer.IpV4,
                (ushort)allocation.RelayServer.Port,
                allocation.AllocationIdBytes,
                allocation.Key,
                allocation.ConnectionData);

            // 4. Start host
            NetworkManager.Singleton.StartHost();
            Debug.Log("[QM] Host started on relay.");

            // 5. Wait for clients to connect, then deal
            await Task.Delay(3000);

            if (NetworkGameManager.Instance != null)
            {
                NetworkGameManager.Instance.InitializeAndDeal();
            }
        }
        catch (System.Exception e)
        {
            Debug.LogError("[QM] Host start failed: " + e.Message);
            OnError?.Invoke("Failed to start game");
        }
    }

    async Task ClientJoinGame()
    {
        try
        {
            // 1. Refresh lobby to get relay code
            currentLobby = await LobbyService.Instance.GetLobbyAsync(currentLobby.Id);

            if (!currentLobby.Data.ContainsKey("relayCode"))
            {
                Debug.LogWarning("[QM] Relay code not yet available, waiting...");
                await Task.Delay(2000);
                currentLobby = await LobbyService.Instance.GetLobbyAsync(currentLobby.Id);
            }

            string relayCode = currentLobby.Data["relayCode"].Value;

            // 2. Join relay
            JoinAllocation allocation =
                await RelayService.Instance.JoinAllocationAsync(relayCode);

            // 3. Configure transport
            var transport = NetworkManager.Singleton.GetComponent<UnityTransport>();
            transport.SetRelayServerData(
                allocation.RelayServer.IpV4,
                (ushort)allocation.RelayServer.Port,
                allocation.AllocationIdBytes,
                allocation.Key,
                allocation.ConnectionData,
                allocation.HostConnectionData);

            // 4. Start client
            NetworkManager.Singleton.StartClient();
            Debug.Log("[QM] Client started on relay.");
        }
        catch (System.Exception e)
        {
            Debug.LogError("[QM] Client join failed: " + e.Message);
            OnError?.Invoke("Failed to join game");
        }
    }

    // ─────────── TIMEOUT ───────────

    void HandleTimeout()
    {
        if (!isSearching) return;
        isSearching = false;
        StartCoroutine(TimeoutRoutine());
    }

    IEnumerator TimeoutRoutine()
    {
        yield return LeaveAndCleanup();
        OnTimeout?.Invoke();
    }

    IEnumerator LeaveAndCleanup()
    {
        if (currentLobby != null)
        {
            var task = LeaveLobbyAsync();
            while (!task.IsCompleted)
                yield return null;
        }

        currentLobby = null;
        isHost = false;
        searchTimer = 0f;
        pollTimer = 0f;
        previousPlayerIds.Clear();
    }

    async Task LeaveLobbyAsync()
    {
        try
        {
            string playerId = AuthenticationService.Instance.PlayerId;

            if (isHost && currentLobby != null)
            {
                await LobbyService.Instance.DeleteLobbyAsync(currentLobby.Id);
            }
            else if (currentLobby != null)
            {
                await LobbyService.Instance.RemovePlayerAsync(
                    currentLobby.Id, playerId);
            }
        }
        catch (System.Exception e)
        {
            Debug.LogWarning("[QM] Leave lobby error: " + e.Message);
        }
    }

    // ─────────── HELPERS ───────────

    string GetPlayerName(Unity.Services.Lobbies.Models.Player player)
    {
        if (player.Id == AuthenticationService.Instance.PlayerId)
            return string.IsNullOrEmpty(ProfileData.PlayerName) ? "Player" : ProfileData.PlayerName;

        if (player.Data != null && player.Data.ContainsKey("name"))
            return player.Data["name"].Value;

        return "Player";
    }

    int GetPlayerAvatarIndex(Unity.Services.Lobbies.Models.Player player)
    {
        if (player.Id == AuthenticationService.Instance.PlayerId)
            return ProfileData.PlayerAvatarIndex;

        if (player.Data != null && player.Data.ContainsKey("avatar"))
        {
            int.TryParse(player.Data["avatar"].Value, out int idx);
            return idx;
        }

        return 0;
    }
}
```

### What this does (line by line):
- **Awake** — Singleton setup (same as before)
- **Update** — Two timers: `searchTimer` (20s timeout) + `pollTimer` (2.5s lobby refresh)
- **FindMatch()** — Tries to join existing "QuickMatch" lobby; if none found, creates a new one. Then sets `isSearching = true` and fires initial player notifications.
- **TryJoinExistingLobby()** — Queries Unity Lobby Service for lobbies named "QuickMatch" with available slots. Joins the first result. Sets `isHost = false`.
- **CreateNewLobby()** — Creates a new public lobby named "QuickMatch" with max 4 players. Sets `isHost = true`.
- **SetMyPlayerData()** — Stores local player's name + avatar index in lobby player data (same pattern as `LobbyManager.CreateLobby()` line 214-232)
- **PollLobby()** — Every 2.5s, refreshes lobby data, detects player changes, checks if all 4 joined
- **DetectPlayerChanges()** — Compares current player IDs vs previously known IDs. Fires `OnPlayerJoined` for new players, `OnPlayerLeft` for removed players
- **NotifyAllPlayers()** — Fires events for all currently-in-lobby players (used on initial join)
- **HandleMatchFound()** — Stops searching, fires `OnMatchFound`, then starts relay flow
- **HostStartGame()** — Creates Relay allocation, stores join code in lobby, configures UnityTransport, starts Netcode host, waits 3s, calls `InitializeAndDeal()` (same pattern as `LobbyManager.CreateRelay()` line 367-392)
- **ClientJoinGame()** — Reads relay code from lobby, joins relay, configures transport, starts Netcode client (same pattern as `LobbyManager.JoinRelay()` line 395-433)
- **HandleTimeout()** — Stops searching, leaves lobby, fires `OnTimeout`
- **LeaveAndCleanup()** — Removes player from lobby (or deletes lobby if host), resets all state
- **GetPlayerName/GetPlayerAvatarIndex** — Extracts player info from lobby data (same logic as `LobbyManager.UpdatePlayerSlotsUI()` line 624-653)

```csharp
using UnityEngine;
using TMPro;
using System.Collections;

public class MatchmakingUIController : MonoBehaviour
{
    public static MatchmakingUIController Instance;

    public GameObject panel;
    public PlayerProfileUI[] playerSlots;
    public TextMeshProUGUI statusText;
    public TextMeshProUGUI timerText;

    private AvatarDatabase avatarDatabase;

    void Awake()
    {
        Instance = this;
    }

    private void OnEnable()
    {
        if (QuickMatchService.Instance != null)
        {
            QuickMatchService.Instance.OnPlayerJoined += HandlePlayerJoined;
            QuickMatchService.Instance.OnPlayerLeft += HandlePlayerLeft;
            QuickMatchService.Instance.OnMatchFound += HandleMatchFound;
            QuickMatchService.Instance.OnTimeout += HandleTimeout;
            QuickMatchService.Instance.OnError += HandleError;
        }
    }

    private void OnDisable()
    {
        if (QuickMatchService.Instance != null)
        {
            QuickMatchService.Instance.OnPlayerJoined -= HandlePlayerJoined;
            QuickMatchService.Instance.OnPlayerLeft -= HandlePlayerLeft;
            QuickMatchService.Instance.OnMatchFound -= HandleMatchFound;
            QuickMatchService.Instance.OnTimeout -= HandleTimeout;
            QuickMatchService.Instance.OnError -= HandleError;
        }
    }

    private void Update()
    {
        if (QuickMatchService.Instance == null) return;
        if (!QuickMatchService.Instance.IsSearching) return;

        timerText.text =
            "TIMER : " +
            Mathf.Ceil(QuickMatchService.Instance.RemainingSeconds) + "s";
    }

    public void StartSearching()
    {
        avatarDatabase = QuickMatchService.Instance?.AvatarDB;

        panel.SetActive(true);

        for (int i = 0; i < playerSlots.Length; i++)
        {
            playerSlots[i]?.SetProfile("Waiting...", null);
        }

        statusText.text = "Searching for players...";
    }

    // ─────────── EVENT HANDLERS ───────────

    private void HandlePlayerJoined(string playerName, int avatarIndex, int slotIndex)
    {
        if (slotIndex < 0 || slotIndex >= playerSlots.Length) return;
        if (playerSlots[slotIndex] == null) return;

        Sprite avatarSprite = GetAvatarSprite(avatarIndex);
        playerSlots[slotIndex].SetProfile(playerName, avatarSprite);

        statusText.text = "Player joined! (" + (slotIndex + 1) + "/" + playerSlots.Length + ")";
        Debug.Log("[QM-UI] Player joined slot " + slotIndex + ": " + playerName);
    }

    private void HandlePlayerLeft(int slotIndex)
    {
        if (slotIndex >= 0 && slotIndex < playerSlots.Length && playerSlots[slotIndex] != null)
        {
            playerSlots[slotIndex].SetProfile("Waiting...", null);
        }

        statusText.text = "Player left...";
    }

    private void HandleMatchFound()
    {
        statusText.text = "Match Found! Starting game...";
        timerText.text = "STARTING...";
    }

    private void HandleError(string errorMessage)
    {
        statusText.text = errorMessage;
    }

    private void HandleTimeout()
    {
        StartCoroutine(HandleNoPlayersFound());
    }

    // ─────────── UI ACTIONS ───────────

    IEnumerator HandleNoPlayersFound()
    {
        timerText.text = "No players found. Switching to offline...";
        yield return new WaitForSeconds(1.5f);
        panel.SetActive(false);
        GameModeManager.isOnlineMode = false;
        OfflineFallback.Enter();
    }

    public void StopSearching()
    {
        panel.SetActive(false);
    }

    public void OnCancelClicked()
    {
        Debug.Log("Matchmaking cancelled by user");
        if (QuickMatchService.Instance != null)
        {
            QuickMatchService.Instance.Cancel();
        }
        StopSearching();
        GameModeManager.isOnlineMode = false;
        var menu = FindAnyObjectByType<MenuController>();
        if (menu != null && menu.MenuUI != null)
        {
            menu.MenuUI.SetActive(true);
        }
        panel.SetActive(false);
    }

    // ─────────── HELPERS ───────────

    Sprite GetAvatarSprite(int avatarIndex)
    {
        if (avatarDatabase != null &&
            avatarDatabase.avatarSprites != null &&
            avatarIndex >= 0 &&
            avatarIndex < avatarDatabase.avatarSprites.Length)
        {
            return avatarDatabase.avatarSprites[avatarIndex];
        }
        return null;
    }
}
```

### What changed:

- **HandlePlayerJoined(string name, int avatarIndex, int slotIndex)** — NEW: Updates the specific player slot with name + avatar sprite (same pattern as `LobbyManager.UpdatePlayerSlotsUI()`)

- **HandleError(string)** — NEW: Shows error in status text

```csharp
using UnityEngine;

public class MatchmakingStarter : MonoBehaviour
{
    void Start()
    {
        if (!GameModeManager.isOnlineMode)
            return;

        Debug.Log("Online mode detected → starting matchmaking");

        if (MatchmakingUIController.Instance != null)
        {
            MatchmakingUIController.Instance.StartSearching();
        }

        if (QuickMatchService.Instance != null)
        {
            QuickMatchService.Instance.FindMatch();
        }
        else
        {
            Debug.LogError("QuickMatchService Instance missing");
        }
    }
}
```

### What changed:
- Removed `myProfileUI` field — no longer needed because `QuickMatchService.NotifyAllPlayers()` fires `OnPlayerJoined` for ALL players including self, and `MatchmakingUIController.HandlePlayerJoined()` updates the slots
- Removed manual avatar lookup code — the service handles it via events now
- Removed `using UnityEngine.Rendering` and `using TMPro` — unused imports

## Flow Diagram

```
Player 1 clicks "Play Online"
  → MenuController.PlayOnline() → isOnlineMode=true → loads GameScene
  → MatchmakingStarter.Start() → calls FindMatch()
  → QuickMatchService.FindMatch()
     → No "QuickMatch" lobby exists → CreateNewLobby() (host)
     → SetMyPlayerData(name, avatar)
     → NotifyAllPlayers() → fires OnPlayerJoined("Player1", avatarIdx, 0)
     → MatchmakingUIController.HandlePlayerJoined() → Slot 0: "Player1" + avatar
     → Slots 1-3: "Waiting..."
  → Timer: 20s countdown, polls every 2.5s

Player 2 clicks "Play Online"
  → Same flow → QuickMatchService.FindMatch()
     → Finds "QuickMatch" lobby → TryJoinExistingLobby() (client)
     → SetMyPlayerData(name, avatar)
     → NotifyAllPlayers() → fires OnPlayerJoined for Player 1 AND Player 2
     → Client UI: Slot 0 = Player1, Slot 1 = Player2, Slots 2-3 = "Waiting..."

  → Player 1's next poll → DetectPlayerChanges() → fires OnPlayerJoined for Player 2
  → Host UI: Slot 0 = Player1, Slot 1 = Player2, Slots 2-3 = "Waiting..."

Player 3, 4 join → same pattern

All 4 players present (any side detects it):
  → HandleMatchFound()
  → isSearching = false
  → OnMatchFound fires → UI shows "Match Found! Starting game..."
  → Host: CreateRelay → store code in lobby → StartHost → InitializeAndDeal
  → Clients: read relay code → join relay → StartClient
  → NetworkGameManager handles the rest (existing code, untouched)
```
