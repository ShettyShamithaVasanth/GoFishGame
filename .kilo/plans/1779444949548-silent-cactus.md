# Plan: Fix Book Formation in Play-with-Friends (Online Multiplayer) Mode

## Problem Summary

In online multiplayer mode, when a player already has 3 cards of a rank and receives the 4th from another player:
1. The 4th card sometimes doesn't visually appear in the hand
2. No book formation animation plays (unlike offline mode where cards animate into a book)
3. After a few seconds, the 4 cards just disappear (due to late state sync)
4. Console shows "book of rank X" but no visual feedback on screen

## Root Causes

### Cause 1: Transferred cards are NOT added to local player's hand in `PlayTurnResultCoroutine`
In the SUCCESS case (GameManager.cs:2132-2145), cards are animated visually but never added to the local `Player` data model. So `RefreshAllHands()` at line 2148 doesn't show the new cards.

### Cause 2: No book animation in online mode
In the SUCCESS case (GameManager.cs:2154-2191), when `data.bookFormed` is true, only a toast message and score update happen. No card collection animation plays. Compare with offline `HandleBook` (GameManager.cs:1417-1478) which animates each card being collected.

### Cause 3: Race condition with DelayedStateSync
`DelayedStateSync(5f)` runs while `PlayTurnResultCoroutine` is still animating. `ApplyPrivateHand` clears and rebuilds the hand even when `turnActionRunning=true` (only visual refresh is skipped, not data modification). This corrupts the data model mid-animation.

### Cause 4: Duplicate book handling
`BookCreatedClientRpc` is sent alongside `TurnResultClientRpc`, causing double toast/score updates. The `TurnResultData` already contains book info (`bookFormed`, `bookRank`, `bookPlayerScore`), making `BookCreatedClientRpc` redundant.

### Step 6: GameManager.cs — Add `PlayNetworkBookAnimation` coroutine
```csharp
IEnumerator PlayNetworkBookAnimation(int playerLocalId, int bookRank, int newScore)
{
    turnActionRunning = true;
    
    int uiIndex = GetUIIndex(playerLocalId);
    Transform playerTransform = uiPlayers[uiIndex].transform;
    Player player = players[playerLocalId];
    
    if (toastUI != null)
    {
        if (player.IsHuman)
            toastUI.ShowToast("Book forming...");
        else
            toastUI.ShowToast(player.PlayerName + " book forming...");
    }
    
    // Create 4 cards of the book rank (all suits)
    Card[] bookCards = new Card[4];
    for (int i = 0; i < 4; i++)
        bookCards[i] = new Card(bookRank, (CardSuit)i);
    
    // Animate each card being collected
    foreach (Card c in bookCards)
    {
        yield return StartCoroutine(
            AnimateCardMove(playerTransform, playerTransform, c, playerLocalId)
        );
        player.PlayerHand.RemoveCard(c);
    }
    
    // Update score
    player.SetScore(newScore);
    uiPlayers[uiIndex].UpdateScore(newScore);
    
    // Show completion toast
    if (toastUI != null)
    {
        if (player.IsHuman)
            toastUI.ShowToastWithAutoHide("You completed a book!", 3f);
        else
            toastUI.ShowToastWithAutoHide(player.PlayerName + " completed a book!", 3f);
    }
    
    RefreshAllHands();
    
    yield return new WaitForSeconds(0.5f);
}
```
