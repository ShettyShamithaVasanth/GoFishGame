# Plan: Fix Animation Sequencing for Book Formation & Deck-to-Hand Cards

## Problem

In both **Offline** and **Online (Play with Friends)** modes, the animation sequence is broken:

**Current behavior:**
- Book formation animation + deck-to-hand card placement happen **simultaneously**
- Then deck-to-hand transformation animation plays again (redundant)

**Desired behavior (like professional Go Fish):**
1. Card transfer/draw animation completes
2. Hand refreshes (player sees new cards)
3. Book formation animation plays fully
4. Deck visual updates (cards removed)
5. THEN cards from deck animate to player's hand (refill)
6. Turn continues or ends

## Root Cause Analysis

### Offline Mode (`GameManager.cs`)

**Bug 1: `CheckForBook()` is fire-and-forget** (line 1426-1471)

`CheckForBook()` calls `StartCoroutine(HandleBook(...))` but does NOT yield on it. This means the calling coroutine continues immediately:

```
TransferCardsWithAnimation() {
    ...
    CheckForBook(toID);              // starts HandleBook as fire-and-forget
    turnActionRunning = false;       // immediately overrides HandleBook's turnActionRunning = true
    Invoke(AISelectRandomTarget);    // schedules AI while book animation still playing!
}
```

**Bug 2: `turnActionRunning` race condition** (lines 1197-1206 in `TransferCardsWithAnimation`, lines 1356 in `DrawCardWithAnimation`)

`HandleBook` sets `turnActionRunning = true` on its first synchronous frame. But control returns to the caller which immediately sets `turnActionRunning = false` and schedules the next AI move. This causes:
- AI turn starts while book animation still playing
- Book animation + next turn's card animations overlap = "simultaneous" appearance

**Bug 3: Duplicate `turnActionRunning = false`** (line 1197-1199 in `TransferCardsWithAnimation`)

Two consecutive `turnActionRunning = false` lines.

### Online Mode (`GameManager.cs` - `PlayTurnResultCoroutine`)

The `PlayTurnResultCoroutine` (line 2184) already uses proper `yield return` sequencing. However:

**Issue 1: `DelayedStateSync` interferes** - Server sends full state sync after 5 seconds (`NetworkGameManager.cs` line 568-577), but full animation chain (ask popup 2s + reply 1.5s + transfer ~1.8s + book ~2.4s + refill ~3s + waits ~5s = ~16s) takes much longer. State sync arrives mid-animation.

**Issue 2: `ApplyPrivateHand` modifies data even when `turnActionRunning` is true** (line 1796-1824) - It clears and re-adds cards to the player's hand regardless of `turnActionRunning`, only skipping the visual refresh. This corrupts the data that animations are reading from.

**Issue 3: Missing visual gap between book and refill** - Book animation ends, then refill immediately starts without showing the updated deck count first.

## Files to Modify

1. **`Assets/Scripts/GameManager.cs`** - Primary changes (offline animation flow + online animation flow)
2. **`Assets/Scripts/NetworkGameManager.cs`** - Increase `DelayedStateSync` delay for online mode

## Implementation Plan

### Step 1: Create a unified `ProcessBookAndRefill` coroutine in `GameManager.cs`

This new coroutine replaces both `CheckForBook` + `HandleBook` for offline mode, ensuring everything is properly chained:

```csharp
IEnumerator ProcessBookAndRefill(int playerID)
{
    var result = GameRules.CheckForBook(players[playerID]);
    if (result == null) yield break;

    int rank = result.Value.rank;
    List<Card> cards = result.Value.cards;

    completedRanks.Add(rank);
    if (selectedRank == rank) selectedRank = -1;
    aiMemory.ClearRank(rank);
    bookJustFormed = true;

    // --- BOOK ANIMATION PHASE ---
    CancelInvoke(nameof(AISelectRandomTarget));
    turnActionRunning = true;

    if (toastUI != null)
    {
        if (players[playerID].IsHuman)
            toastUI.ShowToast("Book forming...");
    }

    int uiIndex = GetUIIndex(playerID);
    Transform fromTransform = uiPlayers[uiIndex].transform;

    foreach (Card c in cards)
    {
        yield return StartCoroutine(
            AnimateCardMove(fromTransform, fromTransform, c, playerID)
        );
        players[playerID].PlayerHand.RemoveCard(c);
    }

    players[playerID].AddPoint();
    players[playerID].LastBookTurn = bookOrderCounter;
    bookOrderCounter++;

    if (toastUI != null)
    {
        if (players[playerID].IsHuman)
            toastUI.ShowToastWithAutoHide("You completed a book!", 3f);
        else
            toastUI.ShowToastWithAutoHide(players[playerID].PlayerName + " completed a book!", 3f);
    }

    uiPlayers[uiIndex].UpdateScore(players[playerID].Score);
    RefreshAllHands();

    // --- DECK EMPTY CHECK (before refill) ---
    if (!GameModeManager.isOnlineMode && deck != null && deck.CardCount() == 0)
    {
        yield return new WaitForSeconds(1f);
        StartCoroutine(EndGameAfterDelay());
        bookJustFormed = false;
        turnActionRunning = false;
        yield break;
    }

    // --- REFILL PHASE (only after book fully completes) ---
    yield return StartCoroutine(RefillHandIfEmpty(playerID));

    bookJustFormed = false;
    turnActionRunning = false;

    // --- POST-REFILL DECK CHECK ---
    if (!GameModeManager.isOnlineMode && deck != null && deck.CardCount() == 0)
    {
        StartCoroutine(EndGameAfterDelay());
    }
}
```

### Step 2: Fix `TransferCardsWithAnimation` - yield on book handling

Change lines 1155-1218 to properly chain the book handling:

```csharp
IEnumerator TransferCardsWithAnimation(int fromID, int toID, List<Card> cards)
{
    if (gameOver) yield break;

    int fromUI = GetUIIndex(fromID);
    int toUI = GetUIIndex(toID);
    Transform fromTransform = uiPlayers[fromUI].transform;
    Transform toTransform = uiPlayers[toUI].transform;

    foreach (Card c in cards)
    {
        yield return StartCoroutine(
            AnimateCardMove(fromTransform, toTransform, c, toID)
        );
        players[toID].AddCard(c);

        aiMemory.AddConfidence(toID, c.Rank, 6f);
        for (int i = 0; i < players.Length; i++)
        {
            if (i != toID)
                aiMemory.AddConfidence(i, c.Rank, -2f);
        }
    }

    yield return new WaitForSeconds(0.25f);
    RefreshAllHands();
    yield return new WaitForSeconds(1.5f);

    // KEY FIX: yield on book+refill (fully sequential)
    yield return StartCoroutine(ProcessBookAndRefill(toID));

    turnActionRunning = false;

    // Continue turn logic AFTER book and refill animations complete
    if (!players[toID].IsHuman && !gameOver)
    {
        Invoke(nameof(AISelectRandomTarget), 2.2f);
    }
    else if (players[toID].IsHuman && !gameOver)
    {
        if (!CurrentPlayerHasValidMoves())
        {
            toastUI.ShowToastWithAutoHide("No valid moves left. Turn ending.", 2.5f);

    }
```

### Step 6: Fix `ApplyPrivateHand` - Don't modify data during animations

Change line 1796-1824 to not modify hand data when `turnActionRunning` is true:

```csharp
public void ApplyPrivateHand(int[] hand)
{
    if (players == null || playerIdToClientId.Count == 0)
        return;

    int myId = GetLocalPlayerId(NetworkManager.Singleton.LocalClientId);
    if (myId == -1) return;

    // Don't modify data during animations - state sync will re-apply later
    if (turnActionRunning) return;

    players[myId].PlayerHand.Clear();
    foreach (int value in hand)
    {
        players[myId].AddCard(ConvertToCard(value));
    }
    RefreshAllHands();
}
```

### Step 8: Fix `ApplyPublicState` - Don't modify data during animations

Same guard for `ApplyPublicState` (lines 1756-1793):

```csharp
public void ApplyPublicState(ulong[] ids, int[] scores, int[] cardCounts)
{
    if (players == null || activePlayers == null)
        return;

    // Don't modify data during animations
    if (turnActionRunning) return;

    // ... rest unchanged, but remove the !turnActionRunning check at the end
    // since we already returned early above
    int myId = GetLocalPlayerId(NetworkManager.Singleton.LocalClientId);
    for (int i = 0; i < ids.Length; i++)
    {
        int localId = GetLocalPlayerId(ids[i]);
        if (localId == -1) continue;
        players[localId].SetScore(scores[i]);

        if (localId != myId)
        {
            int currentCount = players[localId].PlayerHand.Cards.Count;
            int targetCount = cardCounts[i];
            if (currentCount != targetCount)
            {
                players[localId].PlayerHand.Clear();
                for (int j = 0; j < targetCount; j++)
                {
                    players[localId].AddCard(new Card(0, CardSuit.Spade));
                }
            }
        }
    }
    RefreshAllHands();
}
```

## Animation Sequence Summary (After Fix)

### Offline Mode:
```
Ask popup (2s) → Reply popup (1.3s) → Transfer animation → Refresh → Wait (1.5s) →
Book animation → Score update → Refresh → Deck check → Refill animation → Refresh →
Continue turn / End turn
```

### Online Mode:
```
Ask popup (2s) → Reply popup (1.5s) → Transfer animation → Refresh →
Book animation → Score update → Refresh → Deck visual update → Wait (1s) →
Refill animation → Refresh → Continue turn / End turn
```

Each phase completes fully before the next begins. No simultaneous animations.
