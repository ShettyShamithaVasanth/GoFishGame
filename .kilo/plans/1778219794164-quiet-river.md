# Fix Online Multiplayer Go Fish - All Bugs & Complete Event System

## Root Causes Identified (8 Bugs)

### Bug 1: Player names show "Player_0" instead of real names
**File:** `NetworkPlayer.cs:32`
**Problem:** `SetPlayerNameServerRpc("Player_" + OwnerClientId)` always sends generic name.
**Fix:** Change to `SetPlayerNameServerRpc(ProfileData.PlayerName)`.

### Bug 2: Deck not visible on client
**File:** `NetworkGameManager.cs:53` — `deckRemainingCards` is a plain `int`, NOT synced.
**File:** `GameManager.cs:1725` — Client reads `deckRemainingCards` which is 0 on clients.
**Fix:** Make `deckRemainingCards` a `NetworkVariable<int>`, OR rely on the `SyncDeckCountClientRpc` that already exists. The real issue is timing: `InitializeMultiplayer` runs before `SyncDeckCountClientRpc` arrives. Fix: In `InitializeMultiplayer`, start a coroutine that waits for deck count to arrive, OR send deck count as part of `RequestFullStateServerRpc` response.

### Bug 3: Other players' card backs not visible
**File:** `GameManager.cs:1545` — `ApplyPublicState()` only updates scores, ignores `cardCounts`.
**Fix:** In `ApplyPublicState`, for each non-local player, set their hand to have N placeholder cards so `RefreshHand(false)` shows N card backs.

### Bug 4: `RemoveTopDeckVisual()` crashes with NullReferenceException
**File:** `GameManager.cs:958` — `deck.CardCount()` called but `deck` is null in online mode.
**Fix:** Add online-mode guard. In online mode, use `deckVisualCards.Count - 1` instead.

### Bug 5: `DrawCardWithAnimation` crashes with NullReferenceException
**File:** `GameManager.cs:1125` — `deck.CardCount()` called but `deck` is null in online mode.
**Fix:** `DrawCardWithAnimation` should not be called directly in online mode. `PlayTurnResultCoroutine` handles it via `AnimateCardMove` directly.

### Bug 6: `result.bookRank` never set in `RequestCardRpc`
**File:** `NetworkGameManager.cs:307-317` — `CheckForBook` doesn't return which rank was booked.
**Fix:** Modify `CheckForBook` to return the book rank, or track it in `RequestCardRpc`.

### Bug 7: Card transfer animation shows wrong card
**File:** `GameManager.cs:1888` — `ConvertToCard(data.rank * 10)` creates Ace of Spades always.
**Fix:** Send actual card values in `TurnResultData` or just animate card backs for transfers.

### Bug 8: Host turn stuck after `PlayTurnResult`
The host sends `RequestCardRpc`, server processes, sends `TurnResultClientRpc` to ALL including host. But host's `currentPlayer` and turn state may be out of sync since `OnTurnchanged` was commented out.

### Fix 3: Other players' card backs (GameManager.cs - ApplyPublicState)

In `ApplyPublicState`, after updating scores, update each player's hand with placeholder cards:

```csharp
public void ApplyPublicState(ulong[] ids, int[] scores, int[] cardCounts)
{
    if (players == null || activePlayers == null) return;
    
    int myId = GetLocalPlayerId(NetworkManager.Singleton.LocalClientId);
    
    for (int i = 0; i < ids.Length; i++)
    {
        int localId = GetLocalPlayerId(ids[i]);
        if (localId == -1) continue;
        
        players[localId].SetScore(scores[i]);
        
        // Update card count for OTHER players (show card backs)
        if (localId != myId)
        {
            // Sync hand size to show correct number of card backs
            int currentCount = players[localId].PlayerHand.Cards.Count;
            int targetCount = cardCounts[i];
            
            if (currentCount != targetCount)
            {
                players[localId].PlayerHand.Clear();
                for (int j = 0; j < targetCount; j++)
                {
                    players[localId].AddCard(new Card(0, CardSuit.Spade));
                }
            }
        }
    }
    RefreshAllHands();
}
```

### Fix 6: bookRank tracking (NetworkGameManager.cs)

Change `CheckForBook` to return the booked rank:

```csharp
int CheckForBook(NetworkPlayer player)
{
    int bookedRank = -1;
    Dictionary<int, int> count = new Dictionary<int, int>();
    foreach (var card in player.hand)
    {
        int rank = card / 10;
        if (!count.ContainsKey(rank)) count[rank] = 0;
        count[rank]++;
    }
    foreach (var kvp in count)
    {
        if (kvp.Value == 4)
        {
            bookedRank = kvp.Key;
            player.hand.RemoveAll(c => (c / 10) == bookedRank);
            player.completedBooks.Add(bookedRank);
            player.score.Value++;
            BookCreatedClientRpc(player.OwnerClientId, bookedRank, player.score.Value);
        }
    }
    return bookedRank;
}
```

Then in `RequestCardRpc`:
```csharp
int bookedRank = CheckForBook(sender);
result.bookFormed = bookedRank != -1;
if (result.bookFormed)
{
    result.bookRank = bookedRank;
    result.bookPlayerClientId = sender.OwnerClientId;
    result.bookPlayerScore = sender.score.Value;
}
```

### Fix 8: Host turn state sync (NetworkGameManager.cs)

Uncomment `ApplyNetworkTurn` in `OnTurnchanged`:
```csharp
void OnTurnchanged(ulong oldPlayer, ulong newPlayer)
{
    CheckIfMyTurn(newPlayer);
    GameManager gm = FindAnyObjectByType<GameManager>();
    if (gm != null)
        gm.ApplyNetworkTurn(newPlayer);
}
```

But there's a conflict: `PlayTurnResultCoroutine` ALSO sets the turn at the end. When `NextTurn()` is called on the server, `currentTurnPlayerId` changes, which triggers `OnTurnchanged` on ALL clients. This happens BEFORE `TurnResultClientRpc` arrives (network variable sync is fast).

Solution: Don't let `OnTurnchanged` call `ApplyNetworkTurn` during playback. Use a flag:
```csharp
// In GameManager:
private bool isPlayingTurnResult = false;

// In PlayTurnResultCoroutine, set flag:
isPlayingTurnResult = true;
// ... playback ...
isPlayingTurnResult = false;

// In ApplyNetworkTurn:
public void ApplyNetworkTurn(ulong clientId)
{
    if (isPlayingTurnResult) return; // skip during playback
    // ... rest of method
}
```
