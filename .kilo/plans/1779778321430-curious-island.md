# Plan: Professional Hand Refill System (Offline + Online)

## Problem Statement

When any player's hand cards reach 0 in Go Fish, cards should be drawn from the deck:
- If deck >= 5 cards → transfer 5 cards
- If deck < 5 cards → transfer however many remain
- If deck is empty → no transfer (player stays at 0)

### Current State

| Scenario | Offline | Online |
|----------|---------|--------|
| After book forms (hand empty) | **Works** - `RefillHandIfEmpty` in `HandleBook` (line 1456) | **Broken** - `RefillHandIfEmpty` has `if (isOnlineMode) yield break` |
| Turn starts with 0 cards | **Broken** - AI skips turn, human gets stuck | **Broken** - no refill mechanism |
| After transfer leaves player at 0 | **Broken** - no check after transfer | **Broken** - no check after transfer |

## Architecture Principle

**Server-authoritative, no client/host mixing:**
- Server owns ALL game state (deck, hands, scores)
- Server detects empty hand → draws refill cards → includes data in `TurnResultData`
- Client receives data → plays animations → updates local view
- Offline mode uses local `Deck` directly (unchanged pattern)

```csharp
IEnumerator RefillAndThenStartTurn()
{
    yield return StartCoroutine(RefillHandIfEmpty(currentPlayer));

    // After refill, check again — if still empty (deck was empty), skip/end turn
    if (players[currentPlayer].PlayerHand.Cards.Count == 0)
    {
        EndTurn();
        yield break;
    }

    // Re-execute the normal turn start logic (human toast / AI invoke)
    if (players[currentPlayer].IsHuman)
    {
        selectedRank = -1;
        waitingForTarget = false;
        toastUI.ShowToast("Cards drawn! Your turn — select a rank card");
    }
    else
    {
        
        Invoke(nameof(AISelectRandomTarget), 2.2f);
    }
}
```

## Phase 3: Online Mode — Server-Side Refill Logic

### File: `Assets/Scripts/NetworkGameManager.cs`

**Change 3a: New server method `CheckAndRefillHand`**

```csharp
int[] CheckAndRefillHand(NetworkPlayer player)
{
    if (player.hand.Count > 0) return null;
    if (NetworkDeckManager.Instance == null) return null;
    if (NetworkDeckManager.Instance.deck.Count == 0) return null;

    int drawCount = Mathf.Min(5, NetworkDeckManager.Instance.deck.Count);
    List<int> drawnCards = new List<int>();

    for (int i = 0; i < drawCount; i++)
    {
        int card = NetworkDeckManager.Instance.DrawCard();
        if (card == -1) break;
        player.AddCard(card);
        drawnCards.Add(card);
    }

    deckRemainingCards.Value = NetworkDeckManager.Instance.deck.Count;

    Debug.Log(
        $"[SERVER-REFILL] Player Client:{player.OwnerClientId} " +
        $"refilled {drawnCards.Count} cards | " +
        $"DeckRemaining:{NetworkDeckManager.Instance.deck.Count}"
    );

    return drawnCards.Count > 0 ? drawnCards.ToArray() : null;
}
```

**Change 3d: Add turn-start refill in `NextTurn` (line ~388)**

Before advancing the turn, check if next player needs refill. If yes, draw cards and broadcast:

```csharp
public void NextTurn()
{
    if (!IsServer) return;
    var players = NetworkPlayerManager.Instance.players;
    if (players == null || players.Count == 0) return;

    int currentIndex = players.FindIndex(p => p.OwnerClientId == currentTurnPlayerId.Value);
    if (currentIndex == -1) return;

    int nextIndex = (currentIndex + 1) % players.Count;
    NetworkPlayer nextPlayer = players[nextIndex];

    // NEW: Check if next player needs refill at turn start
    int[] refill = CheckAndRefillHand(nextPlayer);
    if (refill != null)
    {
        // Send dedicated refill notification so clients can animate
        RefillHandClientRpc(
            nextPlayer.OwnerClientId,
            refill,
            NetworkDeckManager.Instance.deck.Count
        );
    }

    Debug.Log(
        $"[SERVER-NEXT-TURN] FROM Client:{currentTurnPlayerId.Value} " +
        $"TO Client:{nextPlayer.OwnerClientId}" +
        (refill != null ? $" | Refilled:{refill.Length}" : "")
    );

    currentTurnPlayerId.Value = nextPlayer.OwnerClientId;
}
```

```csharp
public void PlayRefillAnimation(ulong playerClientId, int[] refillCards, int deckRemaining)
{
    if (!GameModeManager.isOnlineMode) return;
    int localId = GetLocalPlayerId(playerClientId);
    if (localId == -1) return;

    StartCoroutine(AnimateOnlineRefill(localId, refillCards, deckRemaining));
}

IEnumerator AnimateOnlineRefill(int playerID, int[] refillCardValues, int deckRemaining)
{
    int uiIndex = GetUIIndex(playerID);
    UIPlayer ui = uiPlayers[uiIndex];

    if (toastUI != null)
    {
        if (players[playerID].IsHuman)
            toastUI.ShowToastWithAutoHide("Your hand was empty — drawing new cards!", 3f);
        else
            toastUI.ShowToastWithAutoHide(players[playerID].PlayerName + " drawing new cards...", 3f);
    }

    int myLocalId = GetLocalPlayerId(NetworkManager.Singleton.LocalClientId);

    foreach (int cardValue in refillCardValues)
    {
        Card card = ConvertToCard(cardValue);

        // Only add to local model if this is MY hand
        if (playerID == myLocalId)
        {
            players[playerID].AddCard(card);
        }

        yield return StartCoroutine(
            AnimateCardMove(deckPosition, ui.transform, card, playerID)
        );
        RemoveTopDeckVisual();
    }

    UpdateDeckVisualCount(deckRemaining);
    RefreshAllHands();
}
```

## Phase 5: Edge Cases & Game Over

### File: `Assets/Scripts/NetworkGameManager.cs`

**Change 5a: Game over when deck is empty**

In `CheckAndRefillHand`, if deck is empty and player hand is empty, no refill occurs. This is correct behavior — the game should end when:
1. Deck is empty
2. Any player has 0 cards and cannot get a refill

Add a check in `NextTurn`: if next player has 0 cards AND deck is 0, trigger game over:
```csharp
if (nextPlayer.hand.Count == 0 && NetworkDeckManager.Instance.deck.Count == 0)

    bool allEmpty = players.TrueForAll(p => p.hand.Count == 0);
    if (allEmpty)
    {
        TriggerOnlineGameOverClientRpc();
        return;
    }
}
```

## Flow Summary

### Offline — Book + Refill:
1. Player forms book → `HandleBook` → `RefillHandIfEmpty` (existing, works)
2. Turn ends → next player's `StartCurrentTurn` → check hand → refill if empty (NEW)
3. Player plays normally with new cards

### Offline — Transfer Depletes Player:
1. Player A asks B → B gives all cards → B has 0 cards
2. B's turn → `StartCurrentTurn` → refill 5 cards from deck (NEW)
3. B plays normally

### Online — Book + Refill:
1. Server: cards transferred → book detected → hand empty → `CheckAndRefillHand`
2. Server: draws up to 5 cards, adds to `NetworkPlayer.hand`
3. Server: `TurnResultData` includes `handRefilled=true`, `refillCards=[...]`
4. Client: `PlayTurnResultCoroutine` → book animation → refill animation
5. State sync confirms final state

### Online — Turn-Start Refill:
1. Server: `NextTurn` → next player has 0 cards → `CheckAndRefillHand`
2. Server: draws cards, sends `RefillHandClientRpc`
3. Client: `PlayRefillAnimation` → animate cards from deck to player
4. Turn starts normally
