# Fix 2 Online Issues — Deck Visibility + Card Animation Order

## Issue 1: Deck Not Visible on Host

The `WaitForDeckThenCreate()` coroutine calls `UpdateDeckVisualCount()` which has `SetActive(true)`. This should work. But on host, there may be a race condition: `BroadcastStateToAll()` runs during turn processing and calls `UpdateDeckVisualCount` which destroys+recreates deck cards. If the initial `WaitForDeckThenCreate` hasn't completed yet, the deck gets cleared.

Also: `CreateDeckVisual()` is already fixed for online mode (uses `deckRemainingCards.Value` and dummy cards). On host, the data is available immediately — no need for coroutine.

### Fix — GameManager.cs `InitializeMultiplayer()`
On host, call `CreateDeckVisual()` directly instead of coroutine:
```csharp
if (cardBackPrefab != null && deckPosition != null)
{
    if (NetworkManager.Singleton.IsServer)
    {
        CreateDeckVisual(); // host has data immediately
    }
    else
    {
        StartCoroutine(WaitForDeckThenCreate()); // client waits for sync
    }
}
```

## Issue 2: Cards Appear in Hand BEFORE Animation

### Root Cause
`NetworkGameManager` calls `BroadcastStateToAll()` IMMEDIATELY after `TurnResultClientRpc()`:
- Line 346 (Go Fish Phase 1)
- Line 352 (Success path)
- Line 444 (Go Fish Phase 2)

`TurnResultClientRpc` → starts `PlayTurnResultCoroutine` (runs over ~4 seconds with animations)
`BroadcastStateToAll` → runs IMMEDIATELY → `SyncPrivateHandClientRpc` → `ApplyPrivateHand()` → line 1637: `RefreshAllHands()` → **shows cards in hand instantly**
Also `ApplyPrivateHand` line 1639: sets `turnActionRunning = false` → **breaks turn flow**

So player sees:
1. Cards suddenly appear in hand (state sync refresh)
2. THEN animation plays (card moving from target/deck)

### Fix — NetworkGameManager.cs
Replace immediate `BroadcastStateToAll()` with delayed sync in all 3 places:
```csharp
StartCoroutine(DelayedStateSync(5f)); // instead of BroadcastStateToAll()
```
5 seconds gives animations time to complete. `PlayTurnResultCoroutine` already handles local state at the right time.

### Fix — GameManager.cs `ApplyPrivateHand()`
Remove `turnActionRunning = false;` (line 1639). Let `PlayTurnResultCoroutine` manage this flag. The state sync setting this to false during animations breaks the flow.
