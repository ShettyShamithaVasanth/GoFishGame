# Plan: Book Formation Animation for Online Multiplayer (Play with Friends)

## Problem

In online mode ("Play with Friends"), when a book is formed:
1. **Card transfer → book**: 4 cards silently disappear without showing the book formation animation
2. **Lucky deck draw → book**: Cards disappear instantly without any visual feedback

The offline mode already has a proper book formation animation via `HandleBook()` coroutine in `GameManager.cs:1417` — cards animate, toast shows, score updates visually. The online mode just shows a toast message and waits 2 seconds, then moves on.

## Root Cause

In `GameManager.PlayTurnResultCoroutine()` (lines 2064–2373), the book handling for online mode (both CASE 1 success at line 2154 and CASE 3 draw at line 2307) only does:
- Set score
- Update score UI
- Show toast
- Wait 2 seconds

There is **no visual book animation** — no cards moving, no `HandleBook()`-style visual feedback. The cards just disappear on the next state sync.

## Solution Overview

Create a dedicated **`BookAnimationController`** class that handles book formation visuals for **both** offline and online modes. This avoids code duplication and keeps MVC clean.

The online flow becomes:
1. Server detects book → sends `TurnResultData` with `bookFormed=true` and `bookRank`
2. Client receives result → plays ask/reply/draw animations as before
3. **NEW**: When `bookFormed=true`, client plays the book animation using `BookAnimationController`
4. After animation completes → state sync removes cards naturally

## Files to Create

### 1. `Assets/Scripts/BookAnimationController.cs` (NEW)

A reusable component that handles the visual book formation animation. Not a MonoBehaviour — a plain C# class instantiated by GameManager.

**Responsibilities:**
- Spawn 4 temporary card visuals for the book rank
- Animate them flying from the player's UI position to a centered "book display" position
- Show a "Book of [Rank]!" label
- Pause briefly for the player to see
- Fade out / remove the display
- Callback when complete

**Key Design:**
```
public class BookAnimationController
{
    private CardData cardData;
    private GameObject cardPrefab;
    private Transform uiParent; // canvas or game scene root
    
    public IEnumerator PlayBookAnimation(
        Transform playerTransform,
        int rank,                    // rank of the book
        CardData cardData,          // for suit sprites
        GameObject cardPrefab,      // for spawning cards
        ToastUI toastUI,            // for messages
        bool isHuman                // for message text
    )
}
```

**Animation Sequence:**
1. Create 4 UICard objects showing all 4 suits of the book rank
2. Position them at the player's UI location initially
3. Animate them (using DOTween) spreading to a centered row with a slight overlap
4. Show a "Book Complete!" toast
5. Wait 2.5 seconds total
6. Fade out and destroy the temporary cards
7. Coroutine completes → caller continues

### 2. No new network messages needed

The existing `TurnResultData` already contains `bookFormed`, `bookRank`, `bookPlayerClientId`, `bookPlayerScore`. This is sufficient.

## Files to Modify

### 3. `Assets/Scripts/GameManager.cs`

**A. Add `BookAnimationController` field:**
```csharp
private BookAnimationController bookAnimationController;
```
Initialize in `Start()` or at first use.

**B. Refactor offline `HandleBook()` (line 1417) to use `BookAnimationController`:**

Currently `HandleBook()` uses `AnimateCardMove()` to move cards from player transform to the same player transform (which doesn't create a meaningful visual). Replace this with a call to `BookAnimationController.PlayBookAnimation()`.

The offline flow changes from:
```
foreach card → AnimateCardMove(player, player, card)
remove cards from hand
add point
update score
refresh hands
```
To:
```
// Remove cards from model first
foreach card → player.RemoveCard(card)
player.AddPoint()
RefreshAllHands()
// Then play visual animation
yield return bookAnimationController.PlayBookAnimation(...)
// Update score UI
uiPlayers[uiIndex].UpdateScore(player.Score)
```

**C. Update `PlayTurnResultCoroutine()` CASE 1 (success + book, line 2154):**

Replace the current toast+wait with:
```csharp
if (data.bookFormed)
{
    int bookLocalId = GetLocalPlayerId(data.bookPlayerClientId);
    int bookUI = GetUIIndex(bookLocalId);
    players[bookLocalId].SetScore(data.bookPlayerScore);
    uiPlayers[bookUI].UpdateScore(data.bookPlayerScore);
    
    yield return StartCoroutine(
        bookAnimationController.PlayBookAnimation(
            uiPlayers[bookUI].transform,
            data.bookRank,
            cardData,
            cardPrefab,
            toastUI,
            players[bookLocalId].IsHuman
        )
    );
}
```

**D. Update `PlayTurnResultCoroutine()` CASE 3 (draw + book, line 2307):**

Same pattern as above — replace toast+wait with `BookAnimationController` call.

**E. Remove redundant `OnNetworkBookCreated()` method (line 1787):**

This method is called by `BookCreatedClientRpc` in `NetworkGameManager`, but it only shows a toast. Since `PlayTurnResultCoroutine` will now handle the full animation, the `BookCreatedClientRpc` / `OnNetworkBookCreated` path becomes redundant and should be removed to avoid duplicate toasts.

### 4. `Assets/Scripts/NetworkGameManager.cs`

**A. Remove `BookCreatedClientRpc()` and its call in `CheckForBook()` (lines 676–694):**

The book notification is already embedded in `TurnResultData` sent via `TurnResultClientRpc`. The separate `BookCreatedClientRpc` causes a duplicate (and premature) toast. Remove it.

**B. Ensure `TurnResultData` has all needed fields for the animation:**

Current fields are sufficient:
- `bookFormed` (bool)
- `bookRank` (int) — used to create the 4 card visuals
- `bookPlayerClientId` (ulong) — to find the UI position
- `bookPlayerScore` (int) — to update score

No new fields needed.

## Detailed Book Animation Flow

### Offline Mode (after refactor)

```
CheckForBook(playerID)
  → GameRules.CheckForBook() returns (rank, cards)
  → Remove cards from player hand model
  → Add point + update score
  → RefreshAllHands()  // cards disappear from hand UI
  → BookAnimationController.PlayBookAnimation()
      → Spawn 4 cards at player position
      → Animate to center display
      → Show toast "Book of [X] complete!"
      → Wait 2.5s
      → Fade out & destroy
  → RefillHandIfEmpty()
  → Continue game flow
```

### Online Mode — Card Transfer (CASE 1: success + book)

```
PlayTurnResultCoroutine(data)
  → Show ask popup (1.5s)
  → Show reply popup "Yes, I have N Xs"
  → Animate transferred cards flying to asker
  → RefreshAllHands()
  → data.bookFormed == true
      → Set score, update score UI
      → BookAnimationController.PlayBookAnimation()
          → Spawn 4 cards at asker's UI position
          → Animate to center display
          → Show toast
          → Wait 2.5s
          → Fade out & destroy
  → Hide popups
  → Update deck visual
  → Reset flags, continue turn
```

### Online Mode — Lucky Draw (CASE 3: draw + book)

```
PlayTurnResultCoroutine(data)
  → Animate deck card flying to asker
  → RefreshAllHands()
  → Show lucky popup if applicable
  → data.bookFormed == true
      → Set score, update score UI
      → BookAnimationController.PlayBookAnimation()
          → Spawn 4 cards at asker's UI position
          → Animate to center display
          → Show toast
          → Wait 2.5s
          → Fade out & destroy
  → Update deck visual
  → Continue/end turn based on data.continueTurn
```
