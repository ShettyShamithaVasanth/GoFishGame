# Plan: Menu Background Animations for Go Fish Game

## Goal
Add professional animated decorations to the main menu panel — floating fish, flapping wings, hovering cards, and pulsing icons on buttons — using the existing sprite assets and DOTween library.

---

## Available Assets (`Assets/art/anim/`)
| Sprite | Purpose |
|---|---|
| `fish_wing.png` | Wing decoration near Play Offline button |
| `card.png`, `cards.png` | Card decoration near Play Offline button |
| `fish1.png` – `fish4.png` | Fish decoration near Play Online button |
| `fish5.png`, `fish6.png` | Fish decoration near Play With Friends button |
| `bubble.png` | Ambient bubbles scattered in background |
| `bg.png` | Background layer |
| `lucky_draw.png` | Icon on Lucky Draw button |
| `free_coin.png` | Icon on Free Coins button |

## Key Constraint: DOTween is already installed
The project uses `DG.Tweening` extensively in `GameManager.cs`. All animations will use DOTween — no new plugin dependencies.

---

## Architecture (MVC Compliant)

### New Script: `Assets/Scripts/MenuAnimationController.cs`

A **single self-contained MonoBehaviour** attached to the `MenuBackground` GameObject. It:
- Receives `Transform` references via `[SerializeField]` Inspector fields (no hardcoding)
- Starts animations in `OnEnable()`, kills them in `OnDisable()`
- Uses DOTween `SetLoops(-1, LoopType.Yoyo)` for infinite ping-pong animations
- Each animation group is a separate method for clarity

### Data Model: `Assets/Scripts/MenuAnimationConfig.cs`
A `ScriptableObject` holding configurable parameters:
- Float amplitudes, durations, rotation ranges
- Allows designers to tune animations without touching code
- No magic numbers in the controller

## Animation Breakdown

### 1. Play Offline Button Area — Wings + Cards
- **Wings (`fish_wing.png`)**: Two wing Image GameObjects positioned left/right of the button
  - `DOScale` breathing (0.9 → 1.1) loop
  - `DORotate` slight flap (-15° → +15°) offset timing on each wing
- **Cards (`card.png`, `cards.png`)**: 2-3 card Images positioned around the button
  - `DOMoveY` gentle floating (±15px)
  - `DORotate` slight tilt (-5° → +5°)
  - Staggered start delays for organic feel

### 2. Play Online Button Area — Fish1–Fish4
- **4 fish images** swimming in a circular/oval path around/behind the button
  - `DOLocalPath` with `PathType.CatmullRom` for smooth swim curves
  - `DORotate` to face movement direction
  - Staggered delays so fish don't overlap
  - Scale pulse (0.95 → 1.05) for lively feel
- Each fish on its own DOTween Sequence

### 3. Play With Friends Button Area — Fish5 + Fish6
- **2 fish images** doing a gentle figure-8 or sine wave pattern
  - `DOMoveY` sine wave bobbing
  - `DOMoveX` horizontal drift
  - `DORotate` banking tilt synced with movement
  - Staggered for natural pair look

### 4. Lucky Draw Button — Icon Animation
- **`lucky_draw.png` icon** as child Image on the button
  - `DOScale` pulse (1.0 → 1.15 → 1.0) with `Ease.InOutFlash`
  - `DORotate` slow continuous spin (0° → 360°) on Z axis
  - Glow effect via `DOFade` on a duplicate glow layer (optional)

### 5. Free Coins Button — Icon Animation
- **`free_coin.png` icon** as child Image on the button
  - `DOScale` bounce (1.0 → 1.2 → 0.9 → 1.0) loop with `Ease.OutBack`
  - `DOMoveY` subtle hop (±5px) synced with scale
  - `DORotate` wobble (-10° → +10°)

### 6. Ambient Background Bubbles
- **`bubble.png`**: 3-5 semi-transparent bubble Images scattered across `MenuBackground`
  - `DOMoveY` slow rise (bottom → top) with `SetLoops(-1)`
  - `DOFade` fade in at bottom, fade out at top
  - Random speeds and sizes for parallax depth
  - On loop complete, randomize X position

## Implementation Steps

### Step 1: Create `MenuAnimationConfig.cs`
- Define `AnimGroup` structs for each button area
- Each group has: `moveAmplitude`, `moveDuration`, `rotateAmplitude`, `rotateDuration`, `scaleAmplitude`, `scaleDuration`
- Make it a `ScriptableObject` for easy Inspector tuning

### Step 2: Create `MenuAnimationController.cs`
- `[SerializeField]` fields for all animated `Transform` references
- `[SerializeField]` reference to `MenuAnimationConfig`
- `OnEnable()`: call `StartAllAnimations()`
- `OnDisable()`: call `StopAllAnimations()` via `DOTween.Kill(this)`
- Methods:
  - `AnimateWingsAndCards()` — offline area
  - `AnimateOnlineFish()` — online area
  - `AnimateFriendsFish()` — friends area
  - `AnimateLuckyDrawIcon()` — lucky draw button
  - `AnimateFreeCoinsIcon()` — free coins button
  - `AnimateBubbles()` — ambient background
- Helper: `CreateLoopTween()` to DRY up common patterns

### Step 3: Modify `MenuController.cs`
- Add `[SerializeField] MenuAnimationController menuAnimationController;`
- In `PlayOffline()`, `PlayOnline()`, `PlayWithFriends()`: call `menuAnimationController.StopAllAnimations()`
- In `CloseFriendsPanel()` when returning to menu: call `menuAnimationController.StartAllAnimations()`

### Step 4: Unity Scene Setup (instructions for developer)
1. Select `MenuBackground` GameObject in scene
2. Add `MenuAnimationController` component
3. Create child GameObjects under `MenuBackground` for each animated element:
   - `OfflineWingL`, `OfflineWingR`, `OfflineCard1`, `OfflineCard2`
   - `OnlineFish1` – `OnlineFish4`
   - `FriendsFish1`, `FriendsFish2`
   - `LuckyDrawIcon`, `FreeCoinsIcon`
   - `Bubble1` – `Bubble5`
4. Add `Image` component to each, assign correct sprite from `Assets/art/anim/`
5. Drag these transforms into the `MenuAnimationController` Inspector fields
6. Create `MenuAnimationConfig` ScriptableObject asset, assign to controller

## Safety Guarantees
- **Offline gameplay**: No changes to `GameManager.SetupGame()` or any game logic
- **Online gameplay**: No changes to `NetworkGameManager`, `NetworkPlayer`, `NetworkDeckManager`
- **Friends lobby**: No changes to `LobbyManager` — only `MenuController.CloseFriendsPanel()` gets animation restart
- **MVC**: Animation is purely a View-layer concern; no game state is modified
- **No hardcoding**: All parameters come from `MenuAnimationConfig` ScriptableObject
- **Performance**: DOTween is lightweight; ~20 concurrent tweens is negligible. Tweens killed on disable.
