# Plan: Fix Card Transfer & Book Animation in Online (Play with Friends) Mode

## Problem Summary

In the "Play with Friends" (online) gameplay, when a player asks for a card rank and receives cards that complete a 4-card book:

1. **Cards sometimes don't visually place** — the transferred cards animate but local hand state isn't updated, so `RefreshAllHands()` shows stale data
2. **Book animation doesn't play** — unlike offline mode where `HandleBook()` plays a full gathering animation, online mode only shows a toast
3. **Cards disappear after a few seconds** — the delayed `DelayedStateSync` (5s) overwrites local state, removing book cards from hand without any visual animation

The offline mode works correctly because `TransferCardsWithAnimation` updates local `Player.PlayerHand` during animation, then `CheckForBook` → `HandleBook` plays the full book animation. Online mode skips all of this.

---

## Root Cause Analysis

### File: `GameManager.cs` — `PlayTurnResultCoroutine` (line ~2073)

**SUCCESS case (line ~2119):**
- Animates cards from target → asker using `AnimateCardMove`
- **Does NOT add cards to local asker's `Player.PlayerHand`**
- **Does NOT remove cards from local target's `Player.PlayerHand`**
- Calls `RefreshAllHands()` which shows stale local state
- When `data.bookFormed` is true: only updates score/toast — **no book animation, no card removal from local hand**

**GO FISH PHASE 2 (line ~2268):**
- Draws card animation plays but card is NOT added to local asker's hand
- When `data.bookFormed` is true: same issue — no animation

**Result:** Cards appear to transfer, but local state is wrong. Then `DelayedStateSync` (5s later) forces the correct state via `ApplyPrivateHand`/`ApplyPublicState`, causing cards to "disappear" because the booked cards were already removed server-side.

### File: `NetworkGameManager.cs` — `DelayedStateSync` (line ~604)
- Runs 5 seconds after turn result
- Calls `BroadcastStateToAll` which overwrites all local state
- This causes the "disappear" behavior when it removes booked cards that were never locally removed

---

## Solution

The fix mirrors the offline flow inside `PlayTurnResultCoroutine`. Only 2 files need changes, and zero offline logic is affected.

### Step 1: Update local hand state during card transfer animation

**File:** `GameManager.cs` — `PlayTurnResultCoroutine`, SUCCESS case (~line 2133-2211)

After animating each transferred card, add it to the local asker's hand and remove from the local target's hand — matching exactly what offline `TransferCardsWithAnimation` does at line 1160:

```csharp
// Current (broken):
foreach (int cardValue in data.transferredCards)
{
    Card card = ConvertToCard(cardValue);
    yield return StartCoroutine(
        AnimateCardMove(targetUI.transform, askerUI.transform, card, asker.PlayerID)
    );
}
RefreshAllHands();

// Fixed:
// First, remove transferred cards from local target's hand
foreach (int cardValue in data.transferredCards)
{
    Card card = ConvertToCard(cardValue);
    // Remove from target's local hand
    target.PlayerHand.RemoveCard(card);
}
// Animate each card
foreach (int cardValue in data.transferredCards)
{
    Card card = ConvertToCard(cardValue);
    yield return StartCoroutine(
        AnimateCardMove(targetUI.transform, askerUI.transform, card, asker.PlayerID)
    );
    // Add to asker's local hand (matching offline TransferCardsWithAnimation)
    players[asker.PlayerID].AddCard(card);
}
// Wait so user sees the new cards
yield return new WaitForSeconds(1.5f);
RefreshAllHands();
```

### Step 2: Play full book animation when book is formed (SUCCESS case)

**File:** `GameManager.cs` — `PlayTurnResultCoroutine`, after the transfer + `RefreshAllHands`

Replace the current "just update score + toast" with the full offline book flow:

```csharp
// Current (broken) — just toast + score:
if (data.bookFormed)
{
    int bookLocalId = GetLocalPlayerId(data.bookPlayerClientId);
    players[bookLocalId].SetScore(data.bookPlayerScore);
    uiPlayers[bookUI].UpdateScore(data.bookPlayerScore);
    toastUI.ShowToastWithAutoHide("You completed a book!", 3f);
    yield return new WaitForSeconds(2f);
}

// Fixed — play full book animation matching offline HandleBook():
if (data.bookFormed)
{
    int bookLocalId = GetLocalPlayerId(data.bookPlayerClientId);
    Player bookPlayer = players[bookLocalId];
    int bookUI = GetUIIndex(bookLocalId);

    // Check local hand for the book cards
    var bookResult = GameRules.CheckForBook(bookPlayer);
    if (bookResult != null)
    {
        List<Card> bookCards = bookResult.Value.cards;
        turnActionRunning = true;

        // Animate book cards gathering (same as offline HandleBook)
        foreach (Card c in bookCards)
        {
            yield return StartCoroutine(
                AnimateCardMove(
                    uiPlayers[bookUI].transform,
                    uiPlayers[bookUI].transform,
                    c, bookLocalId
                )
            );
            bookPlayer.PlayerHand.RemoveCard(c);
        }

        // Update score
        bookPlayer.SetScore(data.bookPlayerScore);
        uiPlayers[bookUI].UpdateScore(data.bookPlayerScore);

        // Toast
        if (toastUI != null)
        {
            if (bookPlayer.IsHuman)
                toastUI.ShowToastWithAutoHide("You completed a book!", 3f);
            else
                toastUI.ShowToastWithAutoHide(bookPlayer.PlayerName + " completed a book!", 3f);
        }

        RefreshAllHands();
        turnActionRunning = false;

        // Wait for book animation to be visible
        yield return new WaitForSeconds(2f);
    }
    else
    {
        // Fallback: just update score + toast (cards already synced from server)
        bookPlayer.SetScore(data.bookPlayerScore);
        uiPlayers[bookUI].UpdateScore(data.bookPlayerScore);
        if (toastUI != null)
        {
            if (bookPlayer.IsHuman)
                toastUI.ShowToastWithAutoHide("You completed a book!", 3f);
            else
                toastUI.ShowToastWithAutoHide(bookPlayer.PlayerName + " completed a book!", 3f);
        }
        yield return new WaitForSeconds(2f);
    }
}
```

### Step 3: Add drawn card to local hand in GO FISH PHASE 2

**File:** `GameManager.cs` — `PlayTurnResultCoroutine`, GO FISH PHASE 2 case (~line 2268)

After the draw animation completes, add the card to the local asker's hand before refreshing:

```csharp
// Current (broken):
yield return StartCoroutine(
    AnimateCardMove(deckPosition, askerUI.transform, drawn, asker.PlayerID)
);
RefreshAllHands();

// Fixed:
yield return StartCoroutine(
    AnimateCardMove(deckPosition, askerUI.transform, drawn, asker.PlayerID)
);
// Add drawn card to local hand (matching offline DrawCardWithAnimation)
players[asker.PlayerID].AddCard(drawn);
yield return new WaitForSeconds(1.5f);
RefreshAllHands();
```

### Step 4: Play full book animation in GO FISH PHASE 2

Same book animation logic as Step 2, applied to the `data.bookFormed` block inside the GO FISH PHASE 2 case. This is the identical pattern — check local hand for 4-of-a-kind, animate gathering, remove cards, update score.

### Step 5: Increase `DelayedStateSync` delay to prevent race conditions

**File:** `NetworkGameManager.cs` — `RequestCardRpc` and `RequestDrawFromDeckRpc`

The `DelayedStateSync(5f)` should not overwrite visuals while book animation is still playing. Increase the delay for the success case from 5s to 8s, giving enough time for transfer animation + book animation:

```csharp
// In RequestCardRpc SUCCESS branch:
TurnResultClientRpc(result);
StartCoroutine(DelayedStateSync(8f)); // was 5f

// In RequestCardRpc GO FISH branch:
TurnResultClientRpc(result);
StartCoroutine(DelayedStateSync(5f)); // keep 5f for go fish phase 1

// In RequestDrawFromDeckRpc:
TurnResultClientRpc(result);
StartCoroutine(DelayedStateSync(8f)); // was 2.5f, needs more time for book animation
```

### Step 6: Skip state sync hand overwrite when animation is running

**File:** `GameManager.cs` — `ApplyPrivateHand` and `ApplyPublicState`

These methods already check `if (!turnActionRunning)` before calling `RefreshAllHands()`. This is correct — the fix above properly sets `turnActionRunning = true` during book animation, so state sync won't corrupt visuals.

No changes needed here, but we should verify the flag is properly set.

## Verification

2. **Go Fish + Book**: Player asks, gets Go Fish → draws from deck → drawn card completes book → should see draw animation → book animation
3. **Transfer without book**: Player receives cards that don't form a book → should see transfer animation → cards stay in hand → turn continues
4. **Offline mode**: All existing offline scenarios should work identically
